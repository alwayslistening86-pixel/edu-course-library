# MA_S02_Data_Analysis_and_Statistical_Techniques - Test: Data analysis and statistical techniques

## How to run this
A real checkpoint in the style of the certification's items (code-output, multiple-select and short code-writing). Give all the items at once, with no hints and no running of code until every answer is in. Then grade against this stage's entry in `rubric.json`.

## Test items
1. A researcher selects every 25th customer from an alphabetical customer list, after a random starting point. This is: Choose every correct option.
   A. stratified sampling
   B. cluster sampling
   C. systematic sampling
   D. quota sampling
2. Which are true of the correlation coefficient r? Choose every correct option.
   A. r can range from -1 to +1
   B. r close to 0 means a strong linear relationship
   C. r squared shows the proportion of variation in y explained by x
   D. A high r proves that x causes y
3. A regression line is y = 120 + 8x, where x is advertising spend (£'000) and y is sales (units). Forecast sales when advertising spend is £15,000. [2 marks]
4. A 4-quarter moving average trend for Q2 is 340 units. The average seasonal variation for Q2 (additive model) is -25. Forecast Q2 sales. [2 marks]
5. Raw material cost £8.00/kg three years ago (the base year, index 100) and £9.20/kg today. Calculate today's price index and the percentage increase. [3 marks]
6. Which spreadsheet feature lets a manager see how total cost changes if the price of one input changes, without retyping every formula? Choose every correct option.
   A. Sorting
   B. What-if analysis
   C. Conditional formatting
   D. Filtering
7. Which sampling methods are non-random? Choose every correct option.
   A. Quota sampling
   B. Simple random sampling
   C. Cluster sampling
   D. Systematic sampling

## Answer key (for the tutor only)
1. Correct: C (exactly these options, no others)
2. Correct: A, C (exactly these options, no others)
3. [2] M1 y = 120 + 8 x 15; A1 = 240 units.
4. [2] M1 forecast = trend + seasonal variation = 340 + (-25); A1 = 315 units.
5. [3] M1 index = (9.20/8.00) x 100 = 115.0; A1 rounded, index = 115; A1 increase = 15.0%.
6. Correct: B (exactly these options, no others)
7. Correct: A (exactly these options, no others)
