# BT_S04_Accounting_and_Finance_Functions_Regulation_and_Financial_Information - Practice: Accounting/finance functions, regulation and financial information

## Goal
Low-stakes practice: the learner predicts or writes first, then runs it to check. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Which part of the finance function reviews the effectiveness of internal controls independently of operational management? Choose every correct option.
   A. Treasury
   B. Financial accounting
   C. Internal audit
   D. Management accounting
2. Name the three stages typically used to describe the money laundering process. [3 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: C (exactly these options, no others)
2. [3] B1 placement; B1 layering; B1 integration.

## How to run it
One item at a time. For output questions the learner commits to a prediction before running anything. Offer a worked explanation only after an attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
