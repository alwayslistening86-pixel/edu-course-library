# MA_S07_Standard_Costing_and_Variance_Analysis - Practice: Standard costing and variance analysis

## Goal
Low-stakes practice: the learner predicts or writes first, then runs it to check. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Standard labour cost is 2 hours @ £10/hour per unit. 500 units are made using 1,050 hours costing £10,395 in total. Calculate the labour rate and efficiency variances. [4 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [4] M1 actual rate = 10,395/1,050 = £9.90/hr; M1 rate variance = (10.00 - 9.90) x 1,050 = £105 (favourable); M1 standard hours for 500 units = 1,000 hrs; A1 efficiency variance = (1,000 - 1,050) x 10.00 = £-500 (adverse, more hours used than standard).

## How to run it
One item at a time. For output questions the learner commits to a prediction before running anything. Offer a worked explanation only after an attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
