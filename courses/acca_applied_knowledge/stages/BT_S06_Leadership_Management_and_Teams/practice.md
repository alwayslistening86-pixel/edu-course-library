# BT_S06_Leadership_Management_and_Teams - Practice: Leadership, management, teams and motivation

## Goal
Low-stakes practice: the learner predicts or writes first, then runs it to check. Mistakes are expected and corrected here, before any grading.

## Practice items
1. According to Herzberg, which of these is a hygiene factor rather than a motivator? Choose every correct option.
   A. Achievement
   B. Recognition
   C. Salary and working conditions
   D. Responsibility
2. Name the Tuckman stage in which a newly formed project team experiences conflict over roles and approach, before agreeing how to work together. [1 mark]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: C (exactly these options, no others)
2. [1] B1 storming.

## How to run it
One item at a time. For output questions the learner commits to a prediction before running anything. Offer a worked explanation only after an attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
