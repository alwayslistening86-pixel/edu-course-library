# BT_S03_Organisational_Structure_Culture_and_Governance - Practice: Organisational structure, culture, governance and sustainable practice

## Goal
Low-stakes practice: the learner predicts or writes first, then runs it to check. Mistakes are expected and corrected here, before any grading.

## Practice items
1. In which organisational structure do staff typically report to both a functional manager and a project manager? Choose every correct option.
   A. Functional
   B. Divisional
   C. Matrix
   D. Flat
2. Using Handy's typology, name the culture type most associated with a small, founder-led business where the founder makes all major decisions personally. [1 mark]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: C (exactly these options, no others)
2. [1] B1 power culture.

## How to run it
One item at a time. For output questions the learner commits to a prediction before running anything. Offer a worked explanation only after an attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
