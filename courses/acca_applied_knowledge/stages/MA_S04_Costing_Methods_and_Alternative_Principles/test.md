# MA_S04_Costing_Methods_and_Alternative_Principles - Test: Costing methods and alternative principles

## How to run this
A real checkpoint in the style of the certification's items (code-output, multiple-select and short code-writing). Give all the items at once, with no hints and no running of code until every answer is in. Then grade against this stage's entry in `rubric.json`.

## Test items
1. Fixed overhead absorption rate is £5/unit. Production is 3,000 units, sales are 3,400 units. State by how much, and in which direction, marginal costing profit differs from absorption costing profit, and why. [3 marks]
2. Process input is 2,000 kg; normal loss is 5% of input, valued at nil. Actual output is 1,870 kg. State the normal loss in kg and the abnormal loss or gain in kg. [3 marks]
3. Which statement about activity-based costing is correct? Choose every correct option.
   A. It uses a single volume-based overhead absorption rate
   B. It uses multiple cost drivers linked to the activities that cause overhead costs
   C. It can only be used in service businesses
   D. It ignores overhead costs entirely
4. Target costing starts from: Choose every correct option.
   A. the firm's existing production cost, plus a margin
   B. a market-determined selling price, working back to a target cost
   C. the previous year's actual cost
   D. the lowest competitor's cost
5. 100 units of work in progress are 100% complete for materials and 50% complete for labour and overheads. State the equivalent units for materials and for labour/overheads. [2 marks]
6. Throughput accounting treats which cost as the only truly variable cost in the short run? Choose every correct option.
   A. Direct labour
   B. Direct material
   C. Fixed production overhead
   D. Selling and distribution overhead
7. Job costing is most suitable for: Choose every correct option.
   A. continuous, homogeneous output such as refined oil
   B. a bespoke, identifiable piece of work such as a custom-built yacht
   C. a hospital's cost per patient-day
   D. none of these; job costing applies only to services

## Answer key (for the tutor only)
1. [3] M1 inventory falls by 400 units; M1 400 x £5 = £2,000; A1 marginal costing profit is £2,000 higher, because absorption costing releases £2,000 of fixed overhead brought forward from opening inventory into this period's cost of sales, on top of the current period's overhead.
2. [3] B1 normal loss = 5% x 2,000 = 100 kg; M1 expected good output = 2,000 - 100 = 1900 kg; A1 actual output 1,870 kg is 30 kg below that, so there is an abnormal loss of 30 kg.
3. Correct: B (exactly these options, no others)
4. Correct: B (exactly these options, no others)
5. [2] A1 materials: 100 equivalent units (100 x 100%); A1 labour/overheads: 50 equivalent units (100 x 50%).
6. Correct: B (exactly these options, no others)
7. Correct: B (exactly these options, no others)
