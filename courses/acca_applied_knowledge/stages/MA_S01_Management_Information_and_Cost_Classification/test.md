# MA_S01_Management_Information_and_Cost_Classification - Test: Management information and cost classification

## How to run this
A real checkpoint in the style of the certification's items (code-output, multiple-select and short code-writing). Give all the items at once, with no hints and no running of code until every answer is in. Then grade against this stage's entry in `rubric.json`.

## Test items
1. Which of these is a characteristic of management accounting rather than financial accounting? Choose every correct option.
   A. Must follow IFRS Accounting Standards
   B. Produced only annually
   C. Not required by law
   D. Aimed mainly at shareholders
2. Which costs are classified by behaviour? Choose every correct option.
   A. Direct material
   B. Fixed
   C. Administration
   D. Variable
3. A cost that is constant in total within a given range of activity, but rises in steps as a new threshold is crossed, is: Choose every correct option.
   A. a pure variable cost
   B. a semi-variable cost
   C. a stepped fixed cost
   D. a sunk cost
4. Total cost is £50,000 for 2,000 units and £62,000 for 3,500 units. Use the high-low method to find the variable cost per unit and estimate total cost at 3,000 units. [4 marks]
5. Which are examples of secondary data? Choose every correct option.
   A. A questionnaire the firm designed and ran itself
   B. Published government trade statistics
   C. A trade journal's industry survey
   D. A stopwatch time study on the factory floor

## Answer key (for the tutor only)
1. Correct: C (exactly these options, no others)
2. Correct: B, D (exactly these options, no others)
3. Correct: C (exactly these options, no others)
4. [4] M1 var/unit = (62,000 - 50,000)/(3,500 - 2,000) = £8.00; M1 fixed = 62,000 - 8.00 x 3,500 = £34,000; M1 cost at 3,000 = 34,000 + 8.00 x 3,000; A1 = £58,000.
5. Correct: B, C (exactly these options, no others)
