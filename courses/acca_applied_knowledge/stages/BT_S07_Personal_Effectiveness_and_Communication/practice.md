# BT_S07_Personal_Effectiveness_and_Communication - Practice: Personal effectiveness, conflict and communication

## Goal
Low-stakes practice: the learner predicts or writes first, then runs it to check. Mistakes are expected and corrected here, before any grading.

## Practice items
1. A task that is important but not urgent should typically be: Choose every correct option.
   A. ignored
   B. deliberately scheduled before it becomes an urgent crisis
   C. delegated regardless of the delegate's workload
   D. done only if there is time left over
2. Name one likely consequence of chronic workplace ineffectiveness for the individual and one for the organisation. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: B (exactly these options, no others)
2. [2] B1 individual: e.g. increased stress, missed deadlines, damaged reputation/career progression (any valid point); B1 organisation: e.g. lost productivity, higher costs, poor customer service, damaged team morale (any valid point).

## How to run it
One item at a time. For output questions the learner commits to a prediction before running anything. Offer a worked explanation only after an attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
