# MA_S03_Materials_Labour_and_Overheads - Lesson: Materials, labour and overheads

## Goal
The learner calculates inventory valuations (FIFO, LIFO, AVCO), the economic order quantity and reorder levels, remuneration under different pay schemes, and overhead absorption rates including over/under absorption.

## Syllabus items taught here
- MA.C1 - Accounting for material, labour and overheads

## How to teach this
Ask why a firm might pay a bonus for output above a target rather than a flat hourly wage, and what could go wrong with that incentive. Have the learner predict the result of every example before running it, and run code for real whenever they can.

#### MA.C1 Accounting for material, labour and overheads
**Accounting for material, labour and overheads.**
**Materials**: inventory is valued as it is issued to production using **FIFO** (first in, first out: issues are costed at the oldest purchase prices, closing inventory at the most recent), **LIFO** (last in, first out: issues at the most recent prices - not permitted under IAS 2 for financial reporting, but may still appear in MA), or **AVCO** (weighted average cost, recalculated after each purchase, or periodically). *Worked example*: opening inventory nil; buy 100 units @ £5.00, then 150 @ £5.20, then 200 @ £5.50; issue 300 units. FIFO cost of issue = 100 x 5.00 + 150 x 5.20 + 50 x 5.50 = £{100 * 5.00 + 150 * 5.20 + 50 * 5.50:,.2f}. Periodic AVCO price = total cost / total units = (100x5.00+150x5.20+200x5.50)/450 = £{(100 * 5.00 + 150 * 5.20 + 200 * 5.50) / 450:.4f}/unit, so AVCO cost of issue = {(100 * 5.00 + 150 * 5.20 + 200 * 5.50) / 450:.4f} x 300 = £{(100 * 5.00 + 150 * 5.20 + 200 * 5.50) / 450 * 300:,.2f}.
The **Economic Order Quantity (EOQ)** minimises the total of ordering costs (which fall as order size rises) and holding costs (which rise with order size): EOQ = sqrt(2 x D x Co / Ch), where D = annual demand, Co = cost per order, Ch = holding cost per unit per year. *Worked example*: D = 10,000 units/year, Co = £25/order, Ch = £2/unit/year. EOQ = sqrt(2 x 10,000 x 25 / 2) = sqrt({2 * 10000 * 25 / 2:,.0f}) = {math.sqrt(2 * 10000 * 25 / 2):.0f} units. The **reorder level** = maximum usage x maximum lead time (to avoid stockouts even in the worst case); **minimum inventory level** = reorder level - (average usage x average lead time); **maximum inventory level** = reorder level + reorder quantity - (minimum usage x minimum lead time).
**Labour remuneration**: time-based (a flat rate per hour, simple but no output incentive), piecework (paid per unit produced, incentivises output but may harm quality; a guaranteed minimum wage is common), and bonus/incentive schemes (e.g. a percentage of time saved against a standard time, shared between worker and employer). *Worked example, piecework with guarantee*: rate £0.80/unit, guaranteed minimum £70/day; a worker makes 100 units in a day: piecework pay = 100 x £0.80 = £{100 * 0.80:.2f}, which exceeds the guarantee so they are paid £{max(100 * 0.80, 70):.2f}.
**Overheads** (indirect costs) are: allocated (charged wholly to one cost centre when traceable, e.g. a supervisor's salary to their own department), apportioned (shared between cost centres on a fair basis, e.g. rent by floor area) for production and service cost centres, then service cost centre costs are **reapportioned** to production cost centres. Each production cost centre then sets an **overhead absorption rate (OAR)** = budgeted overhead / budgeted activity level (e.g. per labour hour, per machine hour), used to charge overhead to each unit produced. **Over/under absorption**: if actual overhead incurred differs from overhead absorbed (OAR x actual activity), the difference is a period profit/loss adjustment. *Worked example*: budgeted overhead £120,000, budgeted machine hours 20,000, so OAR = £{120000 / 20000:.2f}/machine hour. Actual overhead incurred £126,000, actual machine hours 19,000: overhead absorbed = {120000 / 20000:.2f} x 19,000 = £{120000 / 20000 * 19000:,.0f}, less than the £126,000 incurred, so overhead is **under-absorbed** by £{126000 - 120000 / 20000 * 19000:,.0f} (an extra charge against profit).
