## Test items
1. A project costs £15,000. Net cash inflows are £5,000 a year for 4 years. Calculate the payback period and the ARR (using average annual profit over average investment, with the £15,000 depreciated evenly over 4 years). [5 marks]
2. A project costs £20,000 (year 0) and generates £8,000 a year for 3 years. Using discount factors 0.909 (yr1), 0.826 (yr2) and 0.751 (yr3) (10% cost of capital), calculate the NPV and state whether the project should proceed. [5 marks]
3. Which appraisal method(s) account for the time value of money? Choose every correct option.
   A. Payback period
   B. Net present value
   C. Accounting rate of return
   D. None of these
4. A budgetary control report should focus management's attention on: Choose every correct option.
   A. every variance, however small
   B. only material and controllable variances (management by exception)
   C. only favourable variances
   D. only adverse variances
5. Which best describes budgetary slack? Choose every correct option.
   A. A budget set entirely by senior management
   B. A manager deliberately building in an easy target by understating expected performance
   C. A budget that is flexed to actual activity
   D. The gap between the master budget and the cash budget
6. Explain one advantage and one disadvantage of participative (bottom-up) budgeting compared with an imposed (top-down) budget. [4 marks]
