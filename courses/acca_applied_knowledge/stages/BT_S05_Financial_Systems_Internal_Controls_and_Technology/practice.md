# BT_S05_Financial_Systems_Internal_Controls_and_Technology - Practice: Financial systems, internal controls and technology

## Goal
Low-stakes practice: the learner predicts or writes first, then runs it to check. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Splitting the tasks of authorising a payment, making the payment, and recording it in the accounts across different employees is an example of: Choose every correct option.
   A. physical controls
   B. segregation of duties
   C. arithmetic controls
   D. blockchain
2. Name one benefit and one risk of using AI-based anomaly detection in an accounts payable process. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: B (exactly these options, no others)
2. [2] B1 benefit: it can flag unusual or potentially fraudulent transactions faster and more consistently than manual review, at scale (any valid point); B1 risk: it may generate false positives/negatives or embed bias if not properly reviewed by a human, so output still needs human oversight.

## How to run it
One item at a time. For output questions the learner commits to a prediction before running anything. Offer a worked explanation only after an attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
