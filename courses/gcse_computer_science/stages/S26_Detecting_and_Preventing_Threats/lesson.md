# S26_Detecting_and_Preventing_Threats - Lesson: Detecting and preventing cyber security threats

## Goal
The learner explains methods used to detect and prevent cyber security threats: biometric measures, password systems, CAPTCHA, email confirmations and automatic software updates.

## Syllabus items taught here
- 3.6.3 - Methods to detect and prevent threats

## How to teach this
Ask the learner why some websites make them tick boxes with traffic lights or type wiggly letters before logging in. Have the learner predict the output of every Python example before running it, and run code for real whenever they can. AQA's own exams are set in AQA's pseudo-code, not any specific language; Python (AQA's widely-used reference teaching language) is used here so examples can be run for real and their output verified, but the learner should also be shown the equivalent pseudo-code form for exam-style tracing questions, since Paper 1 code-reading/writing questions are set in pseudo-code with only the constructs taught in 3.2. Binary/hex conversions, storage and sound/image size calculations, Huffman/RLE compression and logic-gate truth tables were computed/verified when this course was built.

#### 3.6.3 Methods to detect and prevent threats
Methods to detect and prevent cyber security threats: **biometric measures** use a unique physical characteristic (e.g. a fingerprint or facial recognition) to verify identity, which is much harder for an attacker to steal or guess than a password; **password systems** (requiring strong, sufficiently long/complex passwords, and encouraging or forcing regular changes) make unauthorised access by guessing far harder; **CAPTCHA** presents a test designed to be easy for a human but hard for an automated program, preventing automated bots from, for example, repeatedly guessing passwords or creating fake accounts; **email confirmations** (e.g. sending a code or link to a registered email address, as part of two-step verification) confirm that a login or sensitive action is genuinely being carried out by the real account owner, not just someone who has guessed the password; **automatic software updates** ensure known security vulnerabilities are patched as soon as possible after a fix is released, minimising the time an attacker has to exploit a known weakness.
