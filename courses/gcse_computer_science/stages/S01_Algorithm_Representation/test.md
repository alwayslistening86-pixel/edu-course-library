Give the whole test at once, with no hints and no running of code until every answer is in. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Define the term algorithm. [1 mark]
2. Explain the difference between decomposition and abstraction, using an example of each. [4 marks]
3. An algorithm takes a list of exam marks and works out the average mark. State its input(s), its processing and its output. [3 marks]
4. Which best describes a flowchart's diamond symbol? Choose every correct option.
   A. a decision
   B. an input or output
   C. a process step
   D. the start or end of the algorithm

## Answer key (for the tutor only)
1. [1] B1 a precise, ordered sequence of steps that solves a problem/completes a task.
2. [4] B1 decomposition: breaking a problem into smaller, more manageable sub-problems; B1 example, e.g. splitting 'build a website' into design, content, coding, testing; B1 abstraction: removing unnecessary detail so only relevant information remains; B1 example, e.g. a tube map ignoring true distances/geography.
3. [3] B1 input: the list of marks; B1 processing: sum the marks, divide by how many there are; B1 output: the average mark.
4. Correct: A (exactly these options, no others)
