# S24_Client_Communication - Practice: Communicating with internal and external clients

## Goal
Low-stakes practice: the learner attempts each question with a full answer before seeing the model. Mistakes are expected and corrected here, before any grading.

## Practice items
1. State two things a trainee should check before sending a precedent (template) letter to a client. [4 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [4] B2 that the client's name/details and matter-specific facts are correctly inserted; B2 that any standard content is actually relevant/accurate for this client's circumstances (nothing incorrect or irrelevant is left in); B2 that nothing matter-specific the client needs to be told has been omitted; B2 that the tone/content is appropriate for this particular client -- any 2 for full marks.

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
