# S22_Personal_Impact_and_Teamwork - Practice: Personal impact, working in a team, and setting professional standards

## Goal
Low-stakes practice: the learner attempts each question with a full answer before seeing the model. Mistakes are expected and corrected here, before any grading.

## Practice items
1. State two techniques a trainee could use to manage competing workload demands from different fee earners. [4 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [4] B2 prioritising using an urgency/importance approach; B2 realistically assessing capacity and communicating this proactively; B2 escalating a genuine conflict to a supervisor rather than silently missing a deadline; B2 agreeing revised timescales with the fee earners concerned -- any 2 for full marks.

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
