# S19_Contract_Searches_and_Finance - Practice: Drafting the contract, pre-contract searches and financing a purchase

## Goal
Low-stakes practice: the learner attempts each question with a full answer before seeing the model. Mistakes are expected and corrected here, before any grading.

## Practice items
1. State the difference between a seller's conveyancer holding a deposit as 'stakeholder' and as 'agent'. [3 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] B2 as stakeholder: the deposit cannot be released to the seller before completion, protecting the buyer if the transaction fails; B1 as agent: the deposit can be paid to the seller before completion, which carries more risk for the buyer if the seller then cannot/will not complete.

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
