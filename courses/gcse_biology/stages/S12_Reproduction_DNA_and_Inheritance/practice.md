# S12_Reproduction_DNA_and_Inheritance - Practice: Reproduction, meiosis, DNA structure, the genome and genetic inheritance

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Compare sexual and asexual reproduction in a table on parents, gametes, variation and speed.
2. Draw a Punnett square for two carriers of cystic fibrosis and state the probability of an affected child, and of a carrier child.
3. Explain the difference between genotype and phenotype using an example from pea plants.
4. Higher: write the complementary strand for ATGCCGTA and explain how a change in one base could alter a protein.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
