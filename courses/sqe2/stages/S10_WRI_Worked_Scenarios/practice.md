# S10_WRI_Worked_Scenarios - Practice: Legal writing across the five SQE2 practice-area contexts

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. For the Criminal scenario, write the opening sentence of the letter stating the recommended option clearly.
2. For the Dispute Resolution scenario, write the "consequence of non-compliance" paragraph for the letter before claim (40-60 words).
3. For the Property scenario, write one sentence flagging an outstanding matter (invent a plausible one) in plain English for the buyers.
4. For the Wills scenario, write the reassurance-opening sentence for the executor letter.
5. For the Business scenario, list two points a shareholders' agreement should cover that you would flag in the letter.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
