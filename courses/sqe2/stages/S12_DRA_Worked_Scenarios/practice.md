# S12_DRA_Worked_Scenarios - Practice: Legal drafting across the five SQE2 practice-area contexts

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. For the Criminal scenario, redraft one vague condition ("behave appropriately") into an objectively checkable one.
2. For the Dispute Resolution scenario, draft the one-sentence allegation of breach as a numbered particular.
3. For the Property scenario, draft the "what happens if not satisfied" wording for the retention condition.
4. For the Wills scenario, draft the substitution wording only (if the first beneficiary does not survive, then to X).
5. For the Business scenario, draft the "resolved" wording limiting the director's authority to exactly what was instructed.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
