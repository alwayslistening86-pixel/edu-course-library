# S04_ADV_Worked_Scenarios - Practice: Advocacy across the five SQE2 practice-area contexts

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. For the bail scenario, write the proposed conditions you would offer to answer a flight-risk objection.
2. For the Dispute Resolution scenario, state the summary judgment test in your own words in one sentence.
3. For the Property scenario, list what you must confirm about notice before addressing any tenant defence.
4. For the Wills scenario, write one sentence stating the direction you are seeking, front-loaded as the opening proposition.
5. For the Business scenario, name the three limbs of the interim injunction test you must address.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
