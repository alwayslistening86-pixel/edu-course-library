# S06_CMA_Worked_Scenarios - Practice: Case and matter analysis across the five SQE2 practice-area contexts

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. For the Criminal scenario, list two procedural points and two substantive points you would check in the bundle.
2. For the Dispute Resolution scenario, write one sentence on why the missing signed contract is a decisive, not merely inconvenient, gap.
3. For the Property scenario, list three questions you would raise about the planning condition before advising the buyer.
4. For the Wills scenario, state in one sentence what would distinguish a strong from a weak undue-influence challenge on these facts.
5. For the Business scenario, write the recommendation paragraph (60-80 words) weighing a formal claim against negotiation.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
