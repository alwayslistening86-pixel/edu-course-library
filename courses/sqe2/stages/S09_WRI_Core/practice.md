# S09_WRI_Core - Practice: Legal writing: conventions, attendance notes, letters of advice and other conventional documents

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Rewrite this sentence in plain English for a client: "It would appear that, prima facie, the instant matter may potentially give rise to a cause of action." 
2. Write a 60-word file note recording that a document is missing from the file and needs to be requested from the client.
3. Draft the opening two sentences of a letter of advice confirming the client is entitled to terminate a contract, stating the conclusion first.
4. Write a short, measured email to opposing solicitors requesting an extension of time, avoiding any admission about the underlying dispute.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
