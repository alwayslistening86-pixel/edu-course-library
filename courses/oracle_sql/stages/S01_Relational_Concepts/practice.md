# S01_Relational_Concepts - Practice: Relational databases, ERDs and SQL

## Goal
Low-stakes practice: the learner predicts or writes first, then runs it to check. Mistakes are expected and corrected here, before any grading.

## Practice items
1. In the course schema's ERD, which relationship needs a self-join to follow? (choose one) Choose every correct option.
   A. employee is managed by employee
   B. employee belongs to department
   C. department is located at location
   D. salary falls in job grade
2. Which are DDL statements? (choose two) Choose every correct option.
   A. `TRUNCATE`
   B. `MERGE`
   C. `RENAME`
   D. `SAVEPOINT`

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: A (exactly these options, no others)
2. Correct: A, C (exactly these options, no others)

## How to run it
One item at a time. For output questions the learner commits to a prediction before running anything. Offer a worked explanation only after an attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
