## 8 ready-made items (write the rest fresh, never reusing stage-test items)
1. What does this return in Oracle? (If it fails, give the error and why.)
```sql
SELECT d.department_name, COUNT(e.employee_id) n, NVL(MAX(e.salary), 0) top
FROM departments d LEFT JOIN employees e ON d.department_id = e.department_id
GROUP BY d.department_name HAVING COUNT(e.employee_id) < 2 ORDER BY n, 1;
```
2. What does this return in Oracle? (If it fails, give the error and why.)
```sql
SELECT last_name, TO_CHAR(hire_date, 'fmMonth YYYY') hired FROM employees
WHERE hire_date < ALL (SELECT hire_date FROM employees WHERE department_id = 80) ORDER BY hire_date;
```
3. What does this return in Oracle? (If it fails, give the error and why.)
```sql
SELECT UPPER(SUBSTR(last_name, INSTR(last_name, 'e'))) x, LPAD(ROUND(salary / 1000, 1), 5, '.') k FROM employees WHERE employee_id IN (101, 124) ORDER BY 1;
```
4. What does this return in Oracle? (If it fails, give the error and why.)
```sql
SELECT job_id FROM employees WHERE department_id = 90
MINUS
SELECT job_id FROM employees WHERE salary > 20000
ORDER BY 1;
```
