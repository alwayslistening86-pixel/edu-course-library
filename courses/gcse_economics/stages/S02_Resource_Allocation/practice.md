# S02_Resource_Allocation - Practice: Resource allocation: markets, economic sectors, specialisation

## Goal
Low-stakes practice: the learner attempts each question with full working before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Classify each of the following into primary, secondary or tertiary sector: (a) a fishing trawler crew; (b) a car factory; (c) a firm of accountants. [3 marks]
2. A shoe factory splits production so that one worker only cuts leather, another only stitches, and another only packs boxes. Identify this concept and state one benefit it gives the factory. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] B1 (a) primary; B1 (b) secondary; B1 (c) tertiary.
2. [2] B1 division of labour; B1 e.g. each worker becomes faster/more skilled at their one task, raising output (productivity).

## How to run it
One question at a time. Let the learner finish a genuine attempt (including full working for any calculation) before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
