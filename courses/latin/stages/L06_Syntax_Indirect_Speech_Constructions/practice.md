# L06_Syntax_Indirect_Speech_Constructions - Practice: Syntax — indirect statement, question, command and other required constructions

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Translate: "Puella dīcit sē fessam esse" (note the reflexive sē for "herself").
2. Translate: "Nesciō ubi puer sit," identifying the indirect question.
3. Translate and label: "Imperāvit ut servī labōrārent" versus "Tam fessus erat ut dormīret" — explain how you told them apart.
4. Translate one present open conditional and one past open conditional of your own construction.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
