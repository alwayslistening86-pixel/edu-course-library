# S39_Descriptive_Statistics_and_Data_Handling - Practice: Data handling and descriptive statistics

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Distinguish between nominal and ordinal data, with an example of each. [4 marks]
2. Give one strength and one limitation of using the mean as a measure of central tendency. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [4] B2 nominal data: grouped into named categories with no meaningful numerical relationship between them, e.g. counting how many participants chose each of three response options; B2 ordinal data: can be ranked/ordered, but the exact interval between ranks is not necessarily equal, e.g. a 1-10 self-rated anxiety scale.
2. [2] B1 strength: uses every value in the data set, generally the most sensitive/precise measure; B1 limitation: easily distorted by extreme, outlying values.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
