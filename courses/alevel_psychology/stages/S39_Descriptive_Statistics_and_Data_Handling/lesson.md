#### RM10 Data handling: quantitative/qualitative and primary/secondary data, levels of measurement, descriptive statistics, distributions
**Types of data.** **Quantitative data** is numerical data, expressed in amounts/counts (e.g. reaction time in milliseconds, or number of items recalled); it is generally easier to analyse statistically and compare objectively, but can lack the depth/richness of qualitative data. **Qualitative data** is non-numerical data expressed in words/images (e.g. a transcript of an interview), providing richer, more detailed insight into a participant's experience, but harder to analyse objectively/systematically and to compare or summarise concisely. **Primary data** is data collected first-hand by the researcher specifically for their current investigation; **secondary data** is data that already existed, collected by someone else or for another purpose, which the researcher then uses/reanalyses (e.g. official crime statistics); a **meta-analysis** is a specific form of secondary data analysis, statistically combining the findings of many separate primary studies on the same topic into one overall, more statistically powerful analysis (e.g. Van Ijzendoorn and Kroonenberg's meta-analysis, see ATT8).

**Levels of measurement.** Quantitative data can be measured at different levels, from least to most precise/informative. **Nominal data**: data grouped into separate, named categories, with no meaningful numerical/quantitative relationship between the categories (e.g. counting how many participants chose option A, B or C). **Ordinal data**: data that can be ranked/ordered in terms of size or degree, but the exact numerical difference/interval between ranks is not necessarily equal or meaningful (e.g. a 1-10 self-rated anxiety scale -- a rating of 8 is higher than 4, but not necessarily 'twice as anxious'). **Interval data**: data measured using units of exactly equal, known size, allowing precise, meaningful comparison of the exact numerical difference between any two values (e.g. time in seconds, or temperature in degrees Celsius).

**Measures of central tendency** summarise a data set with a single, typical/representative value. The **mean**: the arithmetic average, calculated by summing all values and dividing by the number of values; strength: uses every value in the data set, generally the most sensitive/precise measure; limitation: easily distorted by extreme, outlying values (anomalies). The **median**: the middle value when all values are arranged in numerical order (or the average of the two middle values, if there is an even number of values); strength: not affected/distorted by extreme values; limitation: does not use every value in the data set, so is less sensitive to the data's full detail than the mean. The **mode**: the most frequently occurring value in the data set (a data set can have more than one mode, or no mode at all if no value repeats); strength: usable with nominal data (unlike the mean or median), and unaffected by extreme values; limitation: does not reflect the data set's full range/detail, and can be unrepresentative or fail to exist in some data sets.

**Measures of dispersion** describe how spread out a data set is. The **range**: the difference between the highest and lowest value in a data set (sometimes with 1 added to correct for continuous data boundaries); strength: quick and easy to calculate; limitation: heavily affected by a single extreme value, and does not reflect the spread of the whole data set (e.g. how clustered the middle values are). The **standard deviation (SD)**: a more precise, sophisticated measure of dispersion, reflecting how far, on average, individual scores in a data set deviate from the mean; a small SD indicates scores are clustered closely around the mean (relatively little variation between participants); a larger SD indicates scores are more widely spread out; strength: uses every value in the data set, giving a precise, sensitive measure of spread; limitation: can be disproportionately affected by extreme values (like the mean), and is more complex to calculate than the range.

**Distributions.** A **normal distribution** is a theoretical, symmetrical, bell-shaped frequency distribution, in which the mean, median and mode all coincide at the exact centre/peak of the curve, and data is distributed symmetrically on either side. A **skewed distribution** is asymmetrical: in a **positive skew**, most values cluster toward the lower end, with a 'tail' of extreme high values pulling the mean above the median, which is in turn above the mode; in a **negative skew**, most values cluster toward the higher end, with a 'tail' of extreme low values pulling the mean below the median, which is in turn below the mode.
