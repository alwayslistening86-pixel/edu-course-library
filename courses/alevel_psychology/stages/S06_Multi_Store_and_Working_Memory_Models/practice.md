# S06_Multi_Store_and_Working_Memory_Models - Practice: The multi-store and working memory models

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Give the capacity and duration of short-term memory according to the multi-store model, naming the researcher associated with each figure. [4 marks]
2. Name the four components of the working memory model. [4 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [4] B2 capacity: approximately 7 +/- 2 items/chunks (Miller, 1956); B2 duration: about 18 seconds without rehearsal (Peterson and Peterson, 1959).
2. [4] B1 B1 B1 B1 each for central executive, phonological loop, visuo-spatial sketchpad, episodic buffer.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
