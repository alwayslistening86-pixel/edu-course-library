# S01_Conformity_Types_and_Explanations - Practice: Types and explanations of conformity

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Distinguish between compliance and internalisation. [3 marks]
2. A student privately still thinks a controversial policy is wrong, but publicly agrees with it whenever their friendship group discusses it. This is an example of: Choose every correct option.
   A. compliance
   B. internalisation
   C. identification with no compliance
   D. informational social influence

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] B1 compliance is a shallow, public-only change in behaviour/opinion that lasts only while the group is present; B1 internalisation is a deep, public-and-private change that persists once the group is no longer present; B1 correctly contrasts the depth/permanence of the change.
2. Correct: A (exactly these options, no others)

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
