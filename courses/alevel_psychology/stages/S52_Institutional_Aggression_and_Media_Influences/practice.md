# S52_Institutional_Aggression_and_Media_Influences - Practice: Institutional aggression and media influences on aggression

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Distinguish between the importation model and the deprivation model of institutional aggression. [2 marks]
2. Name the three proposed mechanisms by which media violence might increase real-world aggression. [3 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 importation model: prisoners bring pre-existing dispositions/values/norms into the prison, which substantially explain aggression there; B1 deprivation model: the stressful, depriving conditions of the prison situation itself produce aggression, regardless of individual disposition.
2. [3] B1 B1 B1 each for desensitisation, disinhibition, cognitive priming.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
