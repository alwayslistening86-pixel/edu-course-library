# S09_Improving_EWT_Cognitive_Interview - Practice: Improving EWT: the cognitive interview

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Name two of the four techniques used in the original cognitive interview. [2 marks]
2. Explain the psychological reasoning behind the 'reinstate the context' technique. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 B1 each for any two of: report everything, reinstate the context, reverse the order, change perspective.
2. [2] B1 based on the encoding specificity principle -- retrieval cues present at encoding help recall if also present at retrieval; B1 recreating the original environmental/emotional context provides those context-dependent/state-dependent cues, improving recall accuracy.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
