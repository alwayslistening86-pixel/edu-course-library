#### RM11 Introduction to inferential testing: probability, significance, Type I/II errors, the sign test, and choosing/using statistical tests
**Probability and significance.** Inferential statistics allow researchers to decide whether a difference/relationship/association found in a sample is likely to be a genuine, meaningful effect (reflecting something true of the wider population) or whether it could plausibly have occurred simply by chance. Psychology conventionally uses a **significance level of p <= 0.05** (a 5% or lower probability that the result occurred by chance) as the threshold for declaring a result 'statistically significant' -- this specific level is a compromise between two types of possible error. A **Type I error** ('optimistic error', false positive) is rejecting a true null hypothesis -- concluding there is a genuine, significant effect when actually there is not; using too lenient/relaxed a significance level (e.g. p <= 0.10) increases the risk of a Type I error. A **Type II error** ('pessimistic error', false negative) is accepting a false null hypothesis -- failing to detect a genuine, significant effect that actually exists; using too strict a significance level (e.g. p <= 0.01) increases the risk of a Type II error. The conventional p <= 0.05 level is generally considered a reasonable balance between these two risks for most psychological research, though a stricter level (e.g. p <= 0.01) may sometimes be used in research (e.g. drug trials) where a false positive (Type I error) would be especially costly/dangerous.

**The sign test.** A simple, non-parametric inferential test, used to analyse the difference between two related/paired sets of scores (a repeated measures or matched pairs design) measured at only the nominal level (specifically, the direction of a difference between each related pair of scores), producing a test statistic conventionally called **S** (or sometimes 'x'). Procedure: for each related pair of scores, calculate the sign of the difference (+ if the score increased, - if it decreased, and any pairs showing no difference are dropped from the analysis, reducing the effective sample size, n); S is then the number of signs in the less frequent direction; this calculated value of S is compared against a critical value in a statistical table, found using the (possibly reduced) value of n and the significance level being used (conventionally p <= 0.05) and whether the hypothesis is one- or two-tailed; for the sign test specifically, the calculated value must be equal to or less than the critical value for the result to be declared statistically significant.

**Choosing and using statistical tests.** The correct inferential test to use for a given set of data depends on three factors: (1) whether the study is testing a **difference** between conditions/groups, or a **correlation/association** between co-variables; (2) the **experimental design** used, where relevant (independent groups/unrelated, or repeated measures or matched pairs/related); and (3) the **level of measurement** of the data (nominal, ordinal, or interval). Commonly used tests include: **Chi-squared test** (for a difference or association in nominal-level, categorical data, using an independent-groups-type design); **Sign test** (a difference, related design, nominal-level data specifically about the direction of change, as above); **Mann-Whitney U test** (a difference, independent groups/unrelated design, at least ordinal-level data); **Wilcoxon signed-rank test** (a difference, repeated measures/related design, at least ordinal-level data); **Spearman's rho** (a correlation, at least ordinal-level data); **Pearson's r** (a correlation, interval-level data that is normally distributed -- a **parametric** test, generally more statistically powerful when its assumptions are met); and the **related or unrelated t-test** (a difference, interval-level, normally distributed data -- parametric tests, related for repeated measures/matched pairs designs, unrelated for independent groups designs). Once the correct test is selected and its calculated value obtained, this value is compared against the appropriate critical value in a statistics table (based on the sample size/degrees of freedom, whether one- or two-tailed, and the chosen significance level) to decide whether the result is statistically significant.
