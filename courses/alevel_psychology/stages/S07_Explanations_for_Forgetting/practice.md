# S07_Explanations_for_Forgetting - Practice: Explanations for forgetting: interference and retrieval failure

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Distinguish between proactive and retroactive interference. [2 marks]
2. Outline what Godden and Baddeley's diving study found about context-dependent forgetting. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 proactive interference: an older memory disrupts recall of a newer one (old interferes with new); B1 retroactive interference: a newer memory disrupts recall of an older one (new interferes with old).
2. [2] B1 recall was significantly better when the environment at learning (on land or underwater) matched the environment at recall than when it did not; B1 correctly attributed to Godden and Baddeley (1975), supporting context-dependent forgetting.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
