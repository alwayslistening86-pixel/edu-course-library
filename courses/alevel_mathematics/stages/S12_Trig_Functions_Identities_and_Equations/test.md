# S12_Trig_Functions_Identities_and_Equations - Test: Reciprocal and inverse trig functions, identities and equations

## How to run this
A real checkpoint in the style of OCR's papers: structured questions with marks shown. Give the whole test at once, with no hints; the learner shows full working and may use a calculator. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Solve 3sin^2 x = 1 + cos x for 0° ≤ x < 360°. [5 marks]
2. Solve sin(2x - 30°) = 0.5 for 0° ≤ x < 360°. [4 marks]
3. Show that (1 + tan^2 x)/(1 + cot^2 x) = tan^2 x. [3 marks]
4. Solve cosec^2 θ - 3cot θ - 5 = 0 for 0 < θ < π, to 3 significant figures. [5 marks]
5. State the domain and range of y = arccos x and find the exact value of arccos(-root3/2). [3 marks]
6. Using small-angle approximations, show that for small θ, (4sin θ tan θ)/(1 - cos 2θ) ≈ 2. [3 marks]

## Answer key (for the tutor only)
1. [5] M1 uses sin^2 = 1 - cos^2; A1 3cos^2 x + cos x - 2 = 0; M1 (3cos x - 2)(cos x + 1) = 0; A1 x = 48.2° or 311.8°; A1 x = 180°.
2. [4] M1 -30° ≤ 2x - 30° < 690°; A1 2x - 30° = 30°, 150°, 390°, 510°; A1 x = 30°, 90°; A1 x = 210°, 270°.
3. [3] M1 uses sec^2 and cosec^2; M1 sec^2 x / cosec^2 x = sin^2 x / cos^2 x; A1 = tan^2 x.
4. [5] M1 uses 1 + cot^2; A1 cot^2 θ - 3cot θ - 4 = 0; M1 cot θ = 4 or -1; A1 θ = 0.245; A1 θ = 3π/4 (2.36).
5. [3] B1 domain -1 ≤ x ≤ 1; B1 range 0 ≤ y ≤ π; B1 5π/6.
6. [3] M1 numerator ≈ 4θ^2; M1 1 - cos 2θ ≈ 2θ^2; A1 ratio 2.
