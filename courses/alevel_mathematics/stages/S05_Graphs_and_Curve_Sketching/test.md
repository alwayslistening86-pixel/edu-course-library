# S05_Graphs_and_Curve_Sketching - Test: Graphs, curve sketching and proportion

## How to run this
A real checkpoint in the style of OCR's papers: structured questions with marks shown. Give the whole test at once, with no hints; the learner shows full working and may use a calculator. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Sketch y = x^2(x - 4), labelling the points where the curve meets the coordinate axes. [3 marks]
2. Sketch y = -(x + 1)(x - 2)^2, labelling intercepts. [3 marks]
3. On the same axes sketch y = 2/x and y = x + 1. Hence state the number of solutions of 2/x = x + 1 and solve it. [5 marks]
4. Use a sketch to explain why x^3 + x - 5 = 0 has exactly one real root. [3 marks]
5. The force F between two magnets is inversely proportional to the square of their distance apart d. F = 20 N when d = 3 cm. Find F when d = 5 cm, and d when F = 45 N. [4 marks]
6. Which describe the graph of y = -3/x^2? Choose every correct option.
   A. It lies entirely below the x-axis
   B. It is symmetric about the y-axis
   C. `It has asymptotes x = 0 and y = 0`
   D. `It passes through (1, 3)`

## Answer key (for the tutor only)
1. [3] B1 positive cubic; B1 touches at the origin (repeated root); B1 crosses at (4, 0).
2. [3] B1 negative cubic shape (top-left to bottom-right); B1 crosses at x = -1, touches at x = 2; B1 y-intercept -(1)(4) = -4.
3. [5] B1 hyperbola in quadrants 1 and 3 with asymptotes; B1 line; B1 two intersections; M1 x^2 + x - 2 = 0; A1 x = 1 or x = -2.
4. [3] M1 writes as x^3 = 5 - x (or considers y = x^3 + x - 5 increasing); M1 y = x^3 is increasing and y = 5 - x is decreasing; A1 so they cross exactly once.
5. [4] M1 F = k/d^2; A1 k = 180; A1 F = 7.2 N; A1 d = 2 cm.
6. Correct: A, B, C (exactly these options, no others)
