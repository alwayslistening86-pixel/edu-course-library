# S01_Proof - Practice: Proof

## Goal
Low-stakes practice: the learner attempts each question with full working before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Prove that the difference between the squares of two consecutive integers is always odd. [3 marks]
2. Show that the statement 'n^2 - n + 11 is prime for every positive integer n' is false. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] M1 let the integers be n and n + 1; M1 (n + 1)^2 - n^2 = 2n + 1; A1 2n + 1 is odd for every integer n, with a conclusion.
2. [2] M1 tries values until a composite appears; A1 n = 11 gives 121 = 11 × 11, not prime (a clear statement that one counter-example disproves it).

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model solution and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
