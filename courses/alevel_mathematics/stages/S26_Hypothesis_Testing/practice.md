# S26_Hypothesis_Testing - Practice: Hypothesis testing

## Goal
Low-stakes practice: the learner attempts each question with full working before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. X ~ B(20, 0.4) under H0: p = 0.4. Find the critical region for a test of H1: p < 0.4 at the 5% level, and the actual significance level. [3 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] M1 finds largest c with P(X ≤ c) ≤ 0.05; A1 X ≤ 3; A1 0.0160.

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model solution and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
