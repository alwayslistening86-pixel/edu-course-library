# S02_Indices_Surds_and_Quadratics - Test: Indices, surds and quadratics

## How to run this
A real checkpoint in the style of OCR's papers: structured questions with marks shown. Give the whole test at once, with no hints; the learner shows full working and may use a calculator. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Solve 4^(x) = 8^(x - 1), giving an exact answer. [3 marks]
2. Rationalise the denominator and simplify (1 + root 2)/(3 - 2 root 2). [3 marks]
3. Express 3x^2 - 12x + 5 in the form a(x + b)^2 + c. Hence write down the coordinates of the turning point of y = 3x^2 - 12x + 5. [4 marks]
4. The equation 2x^2 + kx + 8 = 0 has no real roots. Find the set of possible values of k. [4 marks]
5. Solve x^(2/3) - 5x^(1/3) + 6 = 0. [4 marks]
6. Solve 3x^2 + 7x - 2 = 0, giving your answers in exact form. [3 marks]

## Answer key (for the tutor only)
1. [3] M1 writes both as powers of 2: 2^(2x) = 2^(3x - 3); M1 2x = 3x - 3; A1 x = 3.
2. [3] M1 multiplies top and bottom by 3 + 2 root 2; M1 denominator 9 - 8 = 1; A1 7 + 5 root 2.
3. [4] M1 3(x^2 - 4x) + 5; M1 3(x - 2)^2 - 12 + 5; A1 3(x - 2)^2 - 7; B1 turning point (2, -7).
4. [4] M1 uses b^2 - 4ac < 0; A1 k^2 - 64 < 0; M1 critical values ±8; A1 -8 < k < 8.
5. [4] M1 lets u = x^(1/3): u^2 - 5u + 6 = 0; A1 u = 2 or 3; M1 cubes; A1 x = 8 or 27.
6. [3] M1 correct use of the formula with a = 3, b = 7, c = -2; A1 discriminant 49 + 24 = 73; A1 x = (-7 ± root 73)/6.
