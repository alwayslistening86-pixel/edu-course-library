# S24_Issue_Evaluation_Skills - Practice: Paper 3 issue evaluation: the pre-release booklet, question sequence and reaching a justified decision

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Explain why issue evaluation is described as a 'synoptic' task.
2. Explain the purpose of releasing the resources booklet to students in advance.
3. Identify three possible stakeholders for a hypothetical issue about building a new reservoir, and one interest each might have.
4. Practise writing one paragraph reaching a justified decision on a simple two-option issue, using at least two pieces of 'evidence'.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
