# S11_Coastal_Landforms - Test: Landforms of coastal erosion and deposition, and the Purbeck coastline

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) Name the landform that forms when a cave erodes right through a headland. b) State one difference between a spit and a bar. c) Name one landform found on the Purbeck coast.' Higher (once Foundation is secure): 'Explain, in sequence, how continued erosion of a headland produces first a cave, then an arch, then a stack, and use one example from the Purbeck coast to support your answer.'

## Grading
Apply `rubric.json`'s `stage_rubrics.S11_Coastal_Landforms` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to S12_Coastal_Management.
