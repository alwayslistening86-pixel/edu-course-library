# S11_Coastal_Landforms - Practice: Landforms of coastal erosion and deposition, and the Purbeck coastline

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Put these into the correct order of formation: stack, cave, arch, stump.
2. Explain why headlands erode into caves, arches and stacks while sheltered bays instead build up beaches.
3. Explain the role of marram grass in the formation of a stable sand dune system.
4. Using Purbeck, explain how discordant geology has produced named coastal landforms there.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
