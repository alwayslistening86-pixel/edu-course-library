# S31_Maps_with_Photographs_and_Annotation - Practice: Geographical skills: inferring human activity from OS maps, using and comparing maps with photographs, and annotating

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. List three map symbols that together suggest a location is used for tourism.
2. Describe one change visible between two described maps of the same area at different dates.
3. Draw a simple sketch map from a described view, including a title, key and north arrow.
4. Explain the difference between a ground photograph, an aerial photograph and a satellite image, giving one strength of each.
5. Turn a bare label ('cliff') into a proper annotation explaining what is shown.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
