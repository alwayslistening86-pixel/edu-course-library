# S31_Maps_with_Photographs_and_Annotation - Test: Geographical skills: inferring human activity from OS maps, using and comparing maps with photographs, and annotating

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) Name two symbols that suggest a location is used for tourism. b) What is the difference between a label and an annotation? c) Name one type of photograph other than a ground photograph.' Higher (once Foundation is secure): 'Using a described photograph of a coastal or urban landscape, draw and annotate a field sketch, then compare it against a described OS map extract of the same location, identifying at least two matching features.'

## Grading
Apply `rubric.json`'s `stage_rubrics.S31_Maps_with_Photographs_and_Annotation` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to S32_Graphical_Skills.
