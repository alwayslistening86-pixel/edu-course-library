# S27_Fieldwork_Analysis_and_Conclusions - Test: Enquiry strands 4-6 (part): analysing results, using statistics, identifying anomalies, and reaching conclusions

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) Define an anomaly in fieldwork data. b) Name one statistical technique used to analyse fieldwork data. c) State one problem that can affect data collection.' Higher (once Foundation is secure): 'Using a described set of Cleveleys beach profile results, analyse the pattern using an appropriate statistic, explain one anomaly, and write an evidenced conclusion that answers the enquiry question.'

## Grading
Apply `rubric.json`'s `stage_rubrics.S27_Fieldwork_Analysis_and_Conclusions` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to S28_Fieldwork_Evaluation_and_School_Enquiries.
