# S27_Fieldwork_Analysis_and_Conclusions - Lesson: Enquiry strands 4-6 (part): analysing results, using statistics, identifying anomalies, and reaching conclusions

## Goal
The learner describes, analyses and explains fieldwork results, establishes links between data sets, uses statistical techniques, identifies anomalies, and reaches evidenced conclusions and identifies data collection problems.

## Syllabus items taught here
- 3.3.2.4a - Enquiry strand 4: describing, analysing and explaining results: write about data
- 3.3.2.4b - Enquiry strand 4: establishing links between data sets: relate two data sets
- 3.3.2.4c - Enquiry strand 4: using appropriate statistical techniques: mean, median, IQR, percentages
- 3.3.2.4d - Enquiry strand 4: identifying anomalies: spot and explain outliers
- 3.3.2.5a - Enquiry strand 5: reaching evidenced conclusions: link conclusion to aim
- 3.3.2.6a - Enquiry strand 6: problems of data collection methods: identify problems
- 3.3.2.6b - Enquiry strand 6: limitations of the data collected: identify limitations

## How to teach this
Ask: 'A set of Cleveleys beach profile data mostly shows a clear pattern, but one measurement does not fit. What could explain that one odd result?'

#### 3.3.2.4a Enquiry strand 4: describing, analysing and explaining results
Describing results states what the data shows (for example, 'beach gradient became steeper closer to the sea wall'). Analysing goes further, breaking the pattern down and comparing parts of the data. Explaining results uses geographical knowledge to account for why the pattern exists (for example, linking a steeper gradient near a sea wall to reflected wave energy increasing local erosion, or coarser sediment there because finer material has been washed away).

#### 3.3.2.4b Enquiry strand 4: establishing links between data sets
Strong analysis compares two or more data sets to find relationships: for example, comparing beach profile steepness with distance from existing coastal defences at Cleveleys, or comparing an environmental quality score with distance from the regenerated MediaCityUK core at Salford Quays, to see whether the two factors appear to be linked.

#### 3.3.2.4c Enquiry strand 4: using appropriate statistical techniques
Basic statistical techniques help summarise and compare fieldwork data: the mean (average) gives a typical value; the median (middle value when data is ordered) is less affected by extreme values; and the interquartile range (IQR, the range of the middle 50 percent of ordered data) shows how spread out the more typical results are, which is often more useful than simply noting the full range when a data set contains anomalies.

#### 3.3.2.4d Enquiry strand 4: identifying anomalies
An anomaly is a result that does not fit the general pattern shown by the rest of the data. Spotting anomalies matters because they can reveal a genuine unusual feature (such as a rock outcrop disrupting an otherwise smooth beach profile) or, alternatively, a measurement or recording error; a good enquiry explains which is more likely for each anomaly found, rather than ignoring it.

#### 3.3.2.5a Enquiry strand 5: reaching evidenced conclusions
A conclusion should directly answer the original enquiry question or hypothesis, using specific evidence from the data collected (not vague impressions). For example, a Cleveleys conclusion might state that the data supports the hypothesis that hard engineering has reduced erosion near the sea wall, citing the measured beach profile and sediment size evidence gathered.

#### 3.3.2.6a Enquiry strand 6: problems of data collection methods
Data collection methods can have problems: human error in measuring or recording, unsuitable weather conditions affecting results (or safety), equipment being inaccurate or limited, and time constraints limiting how much data could realistically be collected during a single fieldwork visit, all of which can affect how confidently the results can be used.

#### 3.3.2.6b Enquiry strand 6: limitations of the data collected
Beyond collection problems, the data itself has limitations: a relatively small sample size may not be fully representative of the whole site; data was collected at only one point in time (a single day or season), so it may not reflect conditions at other times of year; and access limitations may have prevented data being collected from every part of the site that would ideally have been included.
