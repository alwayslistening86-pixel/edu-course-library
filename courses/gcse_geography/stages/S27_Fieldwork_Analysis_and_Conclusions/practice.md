# S27_Fieldwork_Analysis_and_Conclusions - Practice: Enquiry strands 4-6 (part): analysing results, using statistics, identifying anomalies, and reaching conclusions

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write one sentence describing a data pattern, then rewrite it to explain why that pattern exists.
2. Explain the difference between mean, median and interquartile range, and when the median might be more useful than the mean.
3. Give a possible geographical explanation and a possible error-based explanation for the same anomaly in a beach profile.
4. Write a short evidenced conclusion for a hypothesis that coastal defences have reduced erosion at Cleveleys.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
