# S30_OS_Maps_Relief_and_Landscape_Features - Test: Geographical skills: OS map relief, cross-sections and drawing inferences about the landscape

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) What do closely spaced contour lines show? b) What is a spot height? c) Name one landscape feature you could identify from contour patterns.' Higher (once Foundation is secure): 'Using a described OS map extract showing a river valley, construct a cross-section along a stated line, then draw and justify one inference about the physical or human landscape using specific map evidence.'

## Grading
Apply `rubric.json`'s `stage_rubrics.S30_OS_Maps_Relief_and_Landscape_Features` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to S31_Maps_with_Photographs_and_Annotation.
