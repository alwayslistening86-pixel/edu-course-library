# S30_OS_Maps_Relief_and_Landscape_Features - Practice: Geographical skills: OS map relief, cross-sections and drawing inferences about the landscape

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Estimate the gradient between two named contour lines on a described map extract.
2. Identify and describe one landscape feature (valley, spur or floodplain) from a described contour pattern.
3. Describe the steps for constructing a cross-section from an OS map.
4. Identify one coastal or one glacial feature from a described large-scale map extract and explain the map evidence used.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
