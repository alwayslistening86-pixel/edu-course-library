# S32_Graphical_Skills - Practice: Geographical skills: selecting, constructing, completing and interpreting graphs, charts and thematic maps

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. State the most appropriate graph type for: (a) monthly temperature data, (b) the proportion of land use types in a city, (c) the relationship between altitude and rainfall.
2. Explain the difference between a choropleth map and an isoline map.
3. Plot a small described data set accurately onto axes with a given scale.
4. Describe the shape of a population pyramid for a country with a high birth rate, and explain what it shows.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
