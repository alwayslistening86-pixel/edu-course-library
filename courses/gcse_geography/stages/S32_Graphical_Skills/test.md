# S32_Graphical_Skills - Test: Geographical skills: selecting, constructing, completing and interpreting graphs, charts and thematic maps

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) Name one graph used to show change over time. b) What does a choropleth map use to show data? c) What does a wide base on a population pyramid usually indicate?' Higher (once Foundation is secure): 'Given a described set of population data for a country, justify the most appropriate graphical technique to show it, then interpret a described population pyramid, explaining what its shape shows about birth rate and age structure.'

## Grading
Apply `rubric.json`'s `stage_rubrics.S32_Graphical_Skills` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to S33_Numerical_and_Statistical_Skills.
