## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) Name the process where embedded rock fragments scrape the glacier bed. b) State one difference between a corrie and a ribbon lake. c) Give one depositional glacial landform.' Higher (once Foundation is secure): 'Explain, using the correct processes, how a single upland area could contain a corrie, an arête, a glacial trough and a terminal moraine, and how each formed.'
