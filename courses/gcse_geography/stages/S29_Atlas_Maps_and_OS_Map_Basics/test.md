# S29_Atlas_Maps_and_OS_Map_Basics - Test: Geographical skills: atlas maps, and OS map scale, grid references and measuring

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) What does a scale of 1:25 000 mean? b) Give the rule for reading a grid reference. c) Name one thing shown on a physical thematic map.' Higher (once Foundation is secure): 'Using a described OS map extract, give a six-figure grid reference for a named feature, measure the straight-line distance between two points, and explain an association you would expect between relief and settlement pattern on the extract.'
