# S29_Atlas_Maps_and_OS_Map_Basics - Practice: Geographical skills: atlas maps, and OS map scale, grid references and measuring

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Give the latitude and longitude of a named city to the nearest whole degree using an atlas.
2. Describe the distribution shown on a named thematic map (for example, world population density), using directions and named regions.
3. Give a four-figure and then a six-figure grid reference for a described map feature.
4. Explain how you would measure the length of a winding footpath on a 1:25 000 OS map.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
