# S33_Numerical_and_Statistical_Skills - Practice: Geographical skills: numerical calculation, fieldwork data reliability, and statistical skills

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Calculate the mean, median, mode and range of a given small data set.
2. Calculate the percentage change between two given values.
3. Explain the difference between interpolation and extrapolation using a described scatter graph.
4. Identify one weakness in a described example of selective statistical presentation and explain why it is misleading.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
