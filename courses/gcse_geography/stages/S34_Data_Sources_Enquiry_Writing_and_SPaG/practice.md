# S34_Data_Sources_Enquiry_Writing_and_SPaG - Practice: Geographical skills: qualitative and quantitative data sources, formulating and writing up enquiry, literacy and SPaG

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Give one example each of primary quantitative, primary qualitative, secondary quantitative and secondary qualitative data for a named enquiry.
2. Explain what GIS is and give one way it could be used in a geographical enquiry.
3. Rewrite a purely descriptive sentence about a graph as an analytical sentence, then as a critical sentence.
4. Plan the five-stage sequence of an enquiry into a locally relevant geographical question.
5. Write a short paragraph reaching an evidenced conclusion on a stated geographical issue, checking spelling, punctuation and correct use of at least two specialist terms.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
