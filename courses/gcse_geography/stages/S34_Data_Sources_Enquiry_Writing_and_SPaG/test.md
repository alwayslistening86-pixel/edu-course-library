# S34_Data_Sources_Enquiry_Writing_and_SPaG - Test: Geographical skills: qualitative and quantitative data sources, formulating and writing up enquiry, literacy and SPaG

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) What is the difference between qualitative and quantitative data? b) Name one digital data source geographers use. c) What is the difference between description and analysis?' Higher (once Foundation is secure): 'Plan an enquiry sequence for a stated geographical question, then write an extended, well-evidenced argument reaching a justified conclusion, using accurate spelling, punctuation, grammar and specialist terminology throughout.'

## Grading
Apply `rubric.json`'s `stage_rubrics.S34_Data_Sources_Enquiry_Writing_and_SPaG` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass. This was the last stage: the cumulative exam is now unlocked once every stage test is passed.
