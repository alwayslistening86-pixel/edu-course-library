# S10_Data_Handling_and_Statistics - Practice: Data handling and descriptive statistics

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Five participants take part in a reaction-time study, and their errors on a task are: 3, 5, 5, 2, 5. Calculate the mean, median and mode of this data, showing your working. [3 marks]
2. State whether each of the following is quantitative or qualitative data: (a) the exact words a participant used to describe a memory; (b) the number of seconds a participant took to respond. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] B1 mean: (3+5+5+2+5)/5 = 20/5 = 4, with working shown; B1 median: sorted 2,3,5,5,5, middle value = 5; B1 mode = 5 (occurs three times, more than any other value).
2. [2] B1 (a) qualitative data; B1 (b) quantitative data.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
