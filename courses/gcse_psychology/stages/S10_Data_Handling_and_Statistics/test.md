# S10_Data_Handling_and_Statistics - Test: Data handling and descriptive statistics

## How to run this
A real checkpoint in the style of AQA's papers: multiple-choice, short-answer, calculation and extended-writing questions, with marks shown. Give the whole test at once, with no hints, before any marking. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Distinguish between primary and secondary data, giving an example of each. [4 marks]
2. Nine participants recall the following numbers of words in a memory test: 5, 6, 6, 7, 8, 9, 9, 9, 10. Calculate the mean, median, mode and range of this data, showing your working. [5 marks]
3. Explain one strength and one weakness of using the mean, compared with the median, to summarise a data set. [2 marks]
4. Describe what a normal distribution looks like, and state the relationship between the mean, median and mode in a perfectly normal distribution. [3 marks]
5. Which graph type is used to display continuous data, with bars drawn touching (no gaps) and area representing frequency? Choose every correct option.
   A. a histogram
   B. a bar chart
   C. a scatter diagram
   D. a frequency table

## Answer key (for the tutor only)
1. [4] B1 primary data is collected first-hand by the researcher for their own study; B1 correct example, e.g. running an experiment themselves; B1 secondary data already existed, collected by someone else for a different original purpose, and is reused; B1 correct example, e.g. official statistics or data from a previous published study.
2. [5] M1 mean: (5+6+6+7+8+9+9+9+10)/9 = 69/9, method shown; A1 mean = 7.67 (accept 7.7 or the exact fraction); B1 median: already ordered with 9 values, the middle (5th) value is 8, so median = 8; B1 mode = 9 (occurs three times, more than any other value); B1 range = 10-5 = 5.
3. [2] B1 strength of the mean, e.g. it uses every value in the data set, making full use of the data; B1 weakness of the mean, e.g. it is distorted by extreme/outlier values, unlike the median which is not affected by them.
4. [3] B1 a symmetrical, bell-shaped curve, with values becoming progressively less frequent further from the centre; B1 correctly described; B1 the mean, median and mode are all equal, at the centre/peak of the curve.
5. Correct: A (exactly these options, no others)
