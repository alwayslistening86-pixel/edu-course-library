# S02_Reconstructive_Memory - Practice: Memory as an active, reconstructive process

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Explain what is meant by 'effort after meaning' in the theory of reconstructive memory. [2 marks]
2. Briefly outline what Bartlett found when participants recalled 'The War of the Ghosts' repeatedly over time. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 when recalling something that does not fit an existing schema, people unconsciously distort/adapt the memory to make it fit better with what they already expect; B1 correctly linked to the idea that this happens without the person realising, making the memory feel accurate.
2. [2] B1 recollections became shorter and were distorted to fit British cultural schemas, e.g. unfamiliar details changed into more familiar ones; B1 correctly attributed to Bartlett (1932).

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
