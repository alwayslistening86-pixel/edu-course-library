# S12_Obedience - Practice: Social influence: obedience

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Explain the difference between an autonomous state and an agentic state in Milgram's agency theory. [2 marks]
2. Briefly explain how proximity affects obedience, according to Milgram's theory. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 autonomous state -- acting according to one's own free will/conscience, feeling personally responsible; B1 agentic state -- seeing oneself as an agent carrying out another's orders, not feeling personally responsible.
2. [2] B1 obedience decreases as the physical/psychological distance between the person and the authority figure or the victim increases; B1 obedience is highest when the authority figure is close by and the victim is more distant/less visible.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
