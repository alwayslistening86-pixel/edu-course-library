# S04_Illusions_and_Perceptual_Set - Test: Visual illusions and factors affecting perception

## Test items
1. Explain, using the Müller-Lyer illusion, what is meant by an illusion caused by 'misinterpreted depth cues'. [3 marks]
2. Name and briefly describe one illusion explained by ambiguity, and one illusion explained by size constancy being miscued. [4 marks]
3. Describe Bruner and Minturn's study and explain what it showed about perceptual set. [4 marks]
4. Explain, giving one named example, how culture can create a perceptual set. [2 marks]
5. Which factor did Gilchrist and Nesberg's study specifically investigate as an influence on perception? Choose every correct option.
   A. motivation (hunger)
   B. culture
   C. emotion
   D. expectation created by context

## Answer key (for the tutor only)
1. [3] B1 two lines of identical length, with different arrow-head/fin directions at the ends, are perceived as different lengths; B1 because monocular depth cues normally used to judge real 3D depth/distance are misapplied to a flat 2D figure; B1 distorting the perceived length even though there is no real depth difference.
2. [4] B1 ambiguity example, e.g. Rubin's vase (seen as either a vase or two faces) or the Necker cube (a cube that flips between two orientations); B1 correctly described; B1 size constancy example, e.g. the Ames Room, making people of different sizes appear equal, or one person appear to change size; B1 correctly described.
3. [4] B1 participants were shown an identical ambiguous figure that could be read as either the letter B or the number 13; B1 whether it was seen as a letter or number depended on the surrounding context (a sequence of letters vs numbers); B1 showing that expectation/context creates a perceptual set that changes what is actually perceived; B1 correctly attributed to Bruner and Minturn.
4. [2] B1 growing up in a particular cultural/visual environment shapes which depth cues, interpretations or perceptual habits feel natural, biasing perception towards culturally familiar interpretations; B1 any reasonable, correctly reasoned example, e.g. someone raised in an environment with few right-angled buildings being less susceptible to a depth-cue illusion that relies on interpreting corners.
5. Correct: A (exactly these options, no others)
