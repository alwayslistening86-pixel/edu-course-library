# S07_Hypotheses_Variables_and_Sampling - Test: Research methods: hypotheses, variables and sampling

## How to run this
A real checkpoint in the style of AQA's papers: multiple-choice, short-answer, calculation and extended-writing questions, with marks shown. Give the whole test at once, with no hints, before any marking. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Write a suitable directional alternative hypothesis for a study investigating whether participants who exercise before a memory test recall more words than participants who do not exercise beforehand. [2 marks]
2. Explain the difference between an extraneous variable and a confounding variable. [2 marks]
3. Describe random sampling and stratified sampling, and state one weakness of each. [4 marks]
4. A researcher selects every 8th name on an alphabetical list of a school's students as their sample. Identify this sampling method, and explain one weakness specific to using an alphabetical list this way. [2 marks]
5. Which sampling method involves identifying sub-groups in the target population and sampling from each in proportion to its size? Choose every correct option.
   A. stratified sampling
   B. opportunity sampling
   C. systematic sampling
   D. random sampling

## Answer key (for the tutor only)
1. [2] B1 correctly directional (states which group will recall more, e.g. 'participants who exercise before the test will recall significantly more words than those who do not'); B1 clearly refers to the actual IV (exercise vs no exercise) and DV (words recalled) of the study.
2. [2] B1 an extraneous variable is any factor, other than the IV, that could potentially affect the DV; B1 a confounding variable is an extraneous variable that was not controlled and did actually affect the DV, making the results impossible to interpret with confidence.
3. [4] B1 random sampling -- every member of the target population has an equal chance of selection; B1 weakness, e.g. can still by chance be unrepresentative, or impractical for a large population; B1 stratified sampling -- sub-groups (strata) identified and sampled from proportionally, usually using random selection within each stratum; B1 weakness, e.g. takes more time/effort to identify strata and sample proportionally.
4. [2] B1 systematic sampling; B1 a reasonable, specific weakness, e.g. if the interval happens to line up with some pattern in the list (such as families or classes grouped together alphabetically), the sample could still be unrepresentative.
5. Correct: A (exactly these options, no others)
