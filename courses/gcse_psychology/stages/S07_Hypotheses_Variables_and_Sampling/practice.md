# S07_Hypotheses_Variables_and_Sampling - Practice: Research methods: hypotheses, variables and sampling

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. A study compares recall scores between a 'music' group and a 'silence' group. Identify the independent variable and the dependent variable. [2 marks]
2. State one strength and one weakness of opportunity sampling. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 independent variable -- whether music is playing or not (music vs silence condition); B1 dependent variable -- the number of words recalled/recall score.
2. [2] B1 one correct strength, e.g. quick/easy/cheap; B1 one correct weakness, e.g. likely to be unrepresentative/biased.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
