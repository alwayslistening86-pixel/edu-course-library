# S03_Perception_Cues_and_Theories - Practice: Perception: sensation, depth cues and theories of perception

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Identify which type of depth cue (monocular or binocular) each of the following is: (a) linear perspective; (b) retinal disparity. [2 marks]
2. Briefly explain what is meant by 'motion parallax' in Gibson's direct theory of perception. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 (a) linear perspective -- monocular; B1 (b) retinal disparity -- binocular.
2. [2] B1 as an observer moves, objects closer to them appear to move faster across the visual field than objects further away; B1 this directly gives information about relative distance, without any need for inference.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
