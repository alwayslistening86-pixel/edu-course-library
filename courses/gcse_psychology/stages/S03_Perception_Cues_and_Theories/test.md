## Test items
1. Distinguish between sensation and perception. [2 marks]
2. Name two monocular depth cues and briefly explain how each helps judge depth. [4 marks]
3. Explain what is meant by size constancy, using an example. [2 marks]
4. Compare Gibson's direct theory of perception with Gregory's constructivist theory. [4 marks]
5. Which depth cue requires the use of both eyes together? Choose every correct option.
   A. retinal disparity
   B. linear perspective
   C. height in plane
   D. relative size

## Answer key (for the tutor only)
1. [2] B1 sensation is the raw physical detection of a stimulus by the sense organs; B1 perception is the psychological process of organising and interpreting that sensory information.
2. [4] B1 e.g. occlusion/interposition -- an object partly blocking another is perceived as nearer; B1 clearly explained; B1 e.g. linear perspective -- parallel lines appear to converge with distance; B1 clearly explained. (Any two genuine monocular cues, correctly explained, credited.)
3. [2] B1 an object is perceived as staying the same real-world size even though its image on the retina changes; B1 correct example, e.g. a person walking away is still perceived as the same size despite their retinal image shrinking.
4. [4] B1 Gibson: perception happens directly from rich information in the environment (e.g. motion parallax), with no need for inference; B1 Gregory: perception is an active, indirect process using past experience/expectation to construct a best-guess interpretation; B1 Gregory's theory better explains illusions/differing interpretations of ambiguous images, since these rely on inference rather than information directly present in the stimulus; B1 both theories correctly and specifically attributed to the right theorist.
5. Correct: A (exactly these options, no others)
