## Test items
1. Name and briefly define the three processes of memory. [3 marks]
2. A participant can remember exactly what they had for breakfast this morning, but cannot easily put into words how they know how to swim. Identify the type of memory involved in each case. [2 marks]
3. Outline the multi-store model of memory, referring to coding, capacity and duration. [4 marks]
4. Explain, referring to Murdock's research, what the serial position curve shows and why it supports the multi-store model. [4 marks]
5. In the multi-store model, which store is typically described as having the smallest capacity and shortest duration? Choose every correct option.
   A. short-term memory
   B. long-term memory
   C. the sensory register only
   D. episodic memory

## Answer key (for the tutor only)
1. [3] B1 encoding -- converting information into a storable form; B1 storage -- retaining encoded information over time; B1 retrieval -- accessing/recovering stored information.
2. [2] B1 breakfast this morning -- episodic memory; B1 knowing how to swim -- procedural memory.
3. [4] B1 three separate stores: sensory register, short-term memory and long-term memory; B1 coding differs between stores, e.g. STM mainly acoustic, LTM mainly semantic; B1 capacity differs, e.g. STM limited, LTM very large; B1 duration differs, e.g. STM brief unless rehearsed, LTM potentially permanent.
4. [4] B1 when recalling a list, people recall the first few items well (primacy effect) and the last few items well (recency effect), but the middle items worst; B1 correctly and specifically attributed to Murdock's serial position/free-recall research; B1 the primacy effect occurs because early items had time to be rehearsed into LTM; B1 the recency effect occurs because the last items are still in STM -- showing STM and LTM behave as separate stores.
5. Correct: A (exactly these options, no others)
