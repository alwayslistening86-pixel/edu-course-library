# S01_Memory_Processes_and_Models - Practice: Memory: processes, types and the multi-store model

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Identify the type of long-term memory (episodic, semantic or procedural) being described: 'knowing how to tie your shoelaces without having to think about each step'. [1 mark]
2. Explain what is meant by the recency effect, and state which memory store it provides evidence for. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [1] B1 procedural memory.
2. [2] B1 the recency effect is the improved recall of the last few items in a list, because they are still held in short-term memory at the point of recall; B1 it provides evidence for short-term memory (STM) as a separate store.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
