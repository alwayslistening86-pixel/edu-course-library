# S08_Experimental_and_Other_Methods - Practice: Research methods: experimental design and other research methods

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. A researcher tests memory for words with and without background noise, using the same 20 participants in both conditions. Identify this experimental design, and state one weakness of using it here. [2 marks]
2. State one strength and one weakness of using a case study. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 repeated measures; B1 a reasonable weakness, e.g. order effects such as practice or fatigue from doing the memory test twice.
2. [2] B1 one correct strength, e.g. very rich/detailed data, useful for rare/unusual cases; B1 one correct weakness, e.g. findings from one case cannot easily be generalised.

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
