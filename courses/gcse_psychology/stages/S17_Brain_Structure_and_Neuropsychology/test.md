# S17_Brain_Structure_and_Neuropsychology - Test: Brain structure, localisation of function and neuropsychology

## How to run this
A real checkpoint in the style of AQA's papers: multiple-choice, short-answer, calculation and extended-writing questions, with marks shown. Give the whole test at once, with no hints, before any marking. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Name the four lobes of the brain, and state one function of the frontal lobe. [3 marks]
2. Describe Penfield's research and explain what it demonstrated about localisation of function. [4 marks]
3. Explain the difference between what a CT scan and an fMRI scan can each show about the brain. [3 marks]
4. Explain how Tulving's research using PET scanning provided evidence about different types of long-term memory. [3 marks]
5. Which brain-scanning technique uses X-rays taken from many angles to build a structural image of the brain? Choose every correct option.
   A. a CT scan
   B. a PET scan
   C. an fMRI scan
   D. an EEG

## Answer key (for the tutor only)
1. [3] B1 frontal, parietal, temporal and occipital lobes named; B1 all four correctly named; B1 one correct frontal lobe function, e.g. movement/motor control, planning or decision-making.
2. [4] B1 the brains of conscious patients undergoing surgery were directly electrically stimulated; B1 stimulating the motor cortex/somatosensory cortex produced specific, localised movements/sensations; B1 stimulating parts of the temporal lobe (the 'interpretive cortex') sometimes triggered vivid memory-like experiences; B1 supporting the idea that specific psychological functions are localised to specific brain regions.
3. [3] B1 a CT scan shows brain structure/physical damage, using X-rays, but not ongoing activity; B1 an fMRI scan shows which brain areas are more active during a task, by measuring changes in blood oxygen levels; B1 correctly contrasted (structure vs function/activity).
4. [3] B1 PET scanning was used to observe brain activity while participants used different types of memory; B1 different types of long-term memory (e.g. episodic and semantic) were associated with distinct, at least partly separate patterns of brain activity; B1 supporting the idea that memory is not handled by a single, uniform brain area.
5. Correct: A (exactly these options, no others)
