# S17_Brain_Structure_and_Neuropsychology - Practice: Brain structure, localisation of function and neuropsychology

## Goal
Low-stakes practice: the learner attempts each question (including full working for any calculation) before seeing the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Name the lobe of the brain primarily responsible for processing visual information. [1 mark]
2. State one difference between a CT scan and a PET scan. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [1] B1 the occipital lobe.
2. [2] B1 a CT scan uses X-rays to show brain structure/physical damage; B1 a PET scan tracks a radioactive tracer to show brain activity/function during a task (any one clearly stated, correct difference).

## How to run it
One question at a time. Let the learner finish a genuine attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
