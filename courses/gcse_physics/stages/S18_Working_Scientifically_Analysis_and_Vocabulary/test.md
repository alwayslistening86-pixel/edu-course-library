# S18_Working_Scientifically_Analysis_and_Vocabulary - Test: Working scientifically: analysis, evaluation and scientific language

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) Calculate the mean of 4.2, 4.5, 4.4 and 4.5 s. b) Name the type of graph you would draw to show the distance travelled by a trolley against time. c) State the SI unit of force and of energy.' Higher (once Foundation is secure): 'Data show the extension of a spring is proportional to the load until 8 N, after which it increases faster. Write a conclusion, evaluate the precision of the data and suggest an improvement.'
