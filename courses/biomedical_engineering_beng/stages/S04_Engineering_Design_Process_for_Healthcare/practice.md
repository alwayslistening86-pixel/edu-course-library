# S04_Engineering_Design_Process_for_Healthcare - Practice: Engineering Design Process for Healthcare

## Goal
Low-stakes practice: the learner attempts each question with full working before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Rewrite the vague requirement 'the inhaler should be easy for elderly patients to use' as two measurable, testable specification requirements. [2 marks]
2. Name the two named techniques for generating a genuine range of design concepts before narrowing down, given in this stage. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B2 (1 mark each, any reasonable measurable pair) e.g. 'operable with one hand exerting no more than 20 N grip force' and 'primed and ready to use within 3 button presses, each requiring under 5 seconds to complete'.
2. [2] B1 morphological analysis (combining different sub-function solutions); B1 biomimicry (drawing on biological solutions).

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
