# S08_Data_Analysis_and_Modelling_for_Bioengineers - Practice: Data Analysis and Modelling for Bioengineers

## Goal
Low-stakes practice: the learner attempts each question with full working before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. A one-compartment model gives clearance CL = k x Vd with k = 0.08 per hour and Vd = 40 L. Calculate CL. [2 marks]
2. State which of a two-sample or a paired comparison is more appropriate for comparing a patient's blood pressure before and after a single intervention, and why. [1 mark]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] M1 CL = 0.08 x 40; A1 = 3.2 L/h.
2. [1] B1 paired, because it removes between-patient variability by comparing each patient to their own baseline, increasing power to detect a real change.

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
