# S12_Biomaterials_II_Drug_Delivery_and_Regenerative_Medicine - Practice: Biomaterials II: Drug Delivery and Regenerative Medicine

## Goal
Low-stakes practice: the learner attempts each question with full working before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. A drug delivery device follows first-order release with rate constant k = 0.15 per day. Calculate the release half-life. [2 marks]
2. State which named biodegradable polymer's degradation rate can be tuned via its lactic:glycolic acid ratio, and name one clinical application area for it from this stage. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] M1 t(1/2) = ln2/k; A1 = 4.62 days.
2. [2] B1 PLGA; B1 any of: drug delivery, tissue-engineering scaffolds.

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
