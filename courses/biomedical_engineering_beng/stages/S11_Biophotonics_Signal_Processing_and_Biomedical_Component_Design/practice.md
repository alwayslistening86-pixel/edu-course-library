# S11_Biophotonics_Signal_Processing_and_Biomedical_Component_Design - Practice: Biophotonics, Signal Processing and Biomedical Component Design

## Goal
Low-stakes practice: the learner attempts each question with full working before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Light of initial intensity 100 units passes through a 1.0 cm absorbing medium with epsilon c = 0.30 per cm. Calculate the transmitted intensity using the Beer-Lambert law (natural-log form). [2 marks]
2. State which imaging modality of the three overviewed in this stage uses no ionising radiation and gives excellent soft-tissue contrast, at the cost of slower acquisition and higher cost. [1 mark]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] M1 I = I0 e^(-epsilon c L) = 100 e^(-0.30x1.0); A1 = 74.1 units.
2. [1] B1 MRI.

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
