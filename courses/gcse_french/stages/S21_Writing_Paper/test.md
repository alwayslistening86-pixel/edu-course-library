# S21_Writing_Paper - Test: Writing paper — Foundation and Higher task types across both tiers

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: "Complète une description de photo (5 phrases), une tâche à cinq points, un texte à trous, et une traduction anglais-français." Higher (once Foundation is secure): "Complète une tâche à trois points et une rédaction ouverte de 150 mots sur deux points, avec plusieurs cadres temporels et des opinions justifiées."

## Grading
Apply `rubric.json`'s `stage_rubrics.S21_Writing_Paper` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass. This was the last stage: the cumulative exam is now unlocked once every stage test is passed.
