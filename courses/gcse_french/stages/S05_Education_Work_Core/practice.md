# S05_Education_Work_Core - Practice: Education and work — vocabulary, perfect and imperfect tenses, near future

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write two sentences about a past school event using the perfect with avoir.
2. Write two sentences using être-verbs in the perfect, with correct agreement (include at least one feminine subject).
3. Combine an event and a judgement using the perfect and the imperfect, as in the worked example.
4. Write three sentences about your plans after Year 11 using aller + infinitive.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
