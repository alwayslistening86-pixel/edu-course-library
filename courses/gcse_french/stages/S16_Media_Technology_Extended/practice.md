# S16_Media_Technology_Extended - Practice: Media and technology — Higher-tier avant de, present participle, depuis and passive

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write one sentence using avant de + infinitive about your evening routine.
2. Write one sentence using a present participle (en + -ant) about doing two things at once.
3. Write one sentence using depuis + present about how long you have owned a device.
4. Write one sentence using the present passive about how news or information spreads.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
