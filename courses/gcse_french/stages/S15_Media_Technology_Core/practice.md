# S15_Media_Technology_Core - Practice: Media and technology — vocabulary, present/perfect contrast, comparatives and connectives

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write one sentence about habitual phone use (present) and one about yesterday's use (perfect).
2. Compare two apps or types of media using a comparative.
3. Give a balanced opinion on social media using mais or cependant.
4. Rewrite using an object pronoun: "Je regarde cette vidéo tous les jours."
5. Join these with a connective: "J'utilise mon portable. Je dois faire mes devoirs."

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
