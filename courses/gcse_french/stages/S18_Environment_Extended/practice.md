# S18_Environment_Extended - Practice: The environment and where people live — Higher-tier relative clauses, negatives, conditional, passive and future

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write one sentence about your area using qui, and one using où or que.
2. Write one sentence using ne...plus or ne...que about an environmental habit.
3. Write one sentence using the conditional about where you would prefer to live.
4. Write one sentence using the passive and one using "si + present, ... + future" about consequences.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
