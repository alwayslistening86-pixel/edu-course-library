# S13_Travel_Tourism_Core - Practice: Travel and tourism — vocabulary, past trips, weather description and place prepositions

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write three sentences narrating a past holiday, using both avoir and être in the perfect.
2. Add weather description using the imperfect to one of your sentences.
3. Fill the gap with à/en/au/aux: "Nous sommes allés ___ Portugal, puis ___ Lisbonne, et enfin ___ États-Unis."
4. Rewrite using an object pronoun: "J'ai visité le musée deux fois."

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
