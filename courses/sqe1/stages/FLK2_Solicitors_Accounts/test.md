# FLK2_Solicitors_Accounts - Test: Solicitors Accounts

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Single-best-answer style: "A solicitor's firm holds £10,000 as client money for a client's property purchase. The firm delivers a bill for £1,500 in costs relating to that matter and notifies the client in writing. Which of the following correctly states what the firm must now do with the £1,500? [Five plausible options, only one correct: the £1,500 must be transferred from the client account to the business account promptly, since it is no longer client money once properly billed.]" The learner must select the correct option and explain why each distractor misapplies the billing trigger, the separation rule, or the withdrawal-authority rule.

## Grading
Apply `rubric.json`'s `stage_rubrics.FLK2_Solicitors_Accounts` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to FLK2_Land_Law.
