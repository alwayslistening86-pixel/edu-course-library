# S01_How_the_Qualification_Works - Test: How the qualification works: three papers, four objectives, SPaG and extended writing

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Answer in short paragraphs. (a) State how many marks each paper is worth, how long it lasts, and where the 8 SPaG marks are found (6 marks). (b) For each of AO1 to AO4, give one sentence explaining what the examiner is rewarding and name one question type in which it is tested (8 marks). (c) Explain, in about 60 words, why an extended answer that only uses the stimulus points given cannot reach the top level (4 marks).

## Grading
Apply `rubric.json`'s `stage_rubrics.S01_How_the_Qualification_Works` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to S02_Second_Order_Concepts_Sources_Interpretations.
