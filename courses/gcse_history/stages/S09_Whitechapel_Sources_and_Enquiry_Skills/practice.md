# S09_Whitechapel_Sources_and_Enquiry_Skills - Practice: Whitechapel enquiries: using historical sources

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Name two local and two national sources useful for an enquiry into how Whitechapel was policed.
2. Give one strength and one weakness of newspaper sources for a Ripper enquiry.
3. Turn the vague topic 'crime in Whitechapel' into a specific, answerable enquiry question.
4. For an enquiry into public fear of the Ripper, name the source type you would prioritise and explain why.
5. Explain why census and crime statistics can both help and mislead a Whitechapel enquiry.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
