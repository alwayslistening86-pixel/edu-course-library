# S10_Paper_1_Question_Types - Practice: Paper 1 question types: thematic study and historic environment

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Answer Q1 style: 'Describe two features of the Bloody Code.'
2. Plan a Q2(a) answer: how useful would a Metropolitan Police annual report and a national newspaper report be for an enquiry into police effectiveness in Whitechapel?
3. Write a Q2(b) follow-up: one further question, one detail, one source type and a reason.
4. Answer Q3 style: explain one similarity between punishment in c1500 and punishment in c1900.
5. Plan a Q5/6 style answer to: 'Attitudes in society were the most important factor in changing definitions of crime, c1000-present. How far do you agree?'

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
