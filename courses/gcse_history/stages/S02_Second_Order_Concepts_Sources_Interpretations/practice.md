# S02_Second_Order_Concepts_Sources_Interpretations - Practice: Second-order concepts, sources and interpretations

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Define causation, consequence, change, continuity, similarity, difference and significance in one sentence each, with an example from any unit.
2. 'The Forest Laws made poaching a crime.' Write one cause and one consequence of this, and say which you think mattered more.
3. Source: a cartoon showing the police failing to catch a criminal in a foggy London alley. Write one inference, then a sentence of provenance you would want (who drew it, for which magazine, when) and one piece of contextual knowledge that could support it.
4. Two historians say: 'The Nazis ruled mainly by terror' and 'The Nazis ruled mainly by consent'. Write one legitimate reason why they might differ.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
