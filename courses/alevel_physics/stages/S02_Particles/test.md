# S02_Particles - Test: Particles, antiparticles and interactions

## How to run this
A real checkpoint in the style of AQA's papers: structured questions with marks shown (and some multiple choice). Give the whole test at once, with no hints; the learner shows working and may use a calculator and the data booklet. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Explain why the existence of the neutrino was hypothesised to account for beta decay. [2 marks]
2. A photon produces an electron-positron pair. Calculate the minimum photon energy in joules and its maximum wavelength. [3 marks]
3. For each interaction, state whether it is possible, giving the conservation law checked or broken: (a) n → p + e^- + ν̄_e; (b) p → n + e^+ + ν̄_e. [4 marks]
4. K+ = us̄. State its charge, baryon number and strangeness, and explain which interaction must be responsible for K+ → π+ + π0. [4 marks]
5. State two differences between hadrons and leptons. [2 marks]
6. Which quantities are always conserved in particle interactions? Choose every correct option.
   A. Charge
   B. Baryon number
   C. Strangeness
   D. Lepton number

## Answer key (for the tutor only)
1. [2] B1 beta particles have a continuous range of kinetic energies up to a maximum; B1 so another particle must carry away the remaining energy (and momentum), conserving energy.
2. [3] M1 2 x 0.511 MeV = 1.64 x 10^-13 J; M1 λ = hc/E; A1 1.22 x 10^-12 m.
3. [4] B1 (a) possible: charge 0 = 1 - 1 + 0, B 1 = 1, L_e 0 = 1 - 1; B1 correct reasoning for (a); B1 (b) not possible; B1 lepton number: 0 ≠ -1 - 1 (a positron has L_e = -1, so a neutrino ν_e is needed, not an antineutrino).
4. [4] B1 +1; B1 0; B1 S = +1; B1 strangeness changes from +1 to 0, so it must be the weak interaction.
5. [2] B1 hadrons feel the strong interaction, leptons don't; B1 hadrons are made of quarks, leptons are fundamental.
6. Correct: A, B, D (exactly these options, no others)
