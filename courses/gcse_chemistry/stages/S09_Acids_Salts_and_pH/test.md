# S09_Acids_Salts_and_pH - Test: Acids, salts, pH and titration (required practicals 1 and 2)

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) Name the salt made from magnesium oxide and hydrochloric acid. b) State the pH of a neutral solution. c) Describe how to tell when a neutralisation is complete using universal indicator.' Higher (once Foundation is secure): 'Explain the difference between a weak acid and a dilute acid, and calculate the concentration of hydrochloric acid if 20.0 cm3 is neutralised by 24.0 cm3 of 0.050 mol/dm3 sodium hydroxide.'
