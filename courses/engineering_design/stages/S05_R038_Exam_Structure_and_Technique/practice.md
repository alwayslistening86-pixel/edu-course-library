# S05_R038_Exam_Structure_and_Technique - Practice: R038 exam structure, command words and level-of-response technique

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. State R038's exam length, mark total and why it must be sat in the final series.
2. List three command words from Appendix B and what kind of answer each expects.
3. Rewrite a brief, one-point answer to a discussion-style question as a developed, two-point Level 3 answer.
4. Explain why using correct technical terminology matters for reaching Level 3, not just having correct ideas.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
