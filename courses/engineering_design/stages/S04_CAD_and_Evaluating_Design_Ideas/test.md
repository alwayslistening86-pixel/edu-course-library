# S04_CAD_and_Evaluating_Design_Ideas - Test: CAD drawing software and evaluating design ideas and outcomes

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Practice scenario (continuing the camping stove): a) Explain one advantage and one limitation of using CAD to develop the stove's design (4). b) Score two rival stove ideas against three specification points in a ranking matrix and state which wins (6). c) Recommend a modelling method for testing the stove's ignition mechanism and justify it (4). d) Write two specific, quantified evaluation findings comparing a built prototype against the specification (6). This tests understanding, not a finished model.
