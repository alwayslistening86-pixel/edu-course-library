# S03_Manufacturing_Considerations_and_Communicating_Outcomes - Practice: Manufacturing considerations, design influences and communicating design outcomes

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Explain how manufacturing scale (one-off versus mass production) would change the process chosen to make the same part.
2. Explain the difference between market pull and technology push with an example of each.
3. Name the drawing type best suited to quickly capturing a new idea versus one best suited to accurate manufacture.
4. List the BS 8888 conventions a correct orthographic working drawing must include.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
