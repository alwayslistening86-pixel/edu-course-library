# S06_R039_Overview_Freehand_Proposals_and_Development - Practice: R039 overview, freehand design proposals and developing a proposal further

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. State R039's four tasks and the mark bands used to assess them.
2. Sketch two genuinely different design proposals for a simple product, using at least one rendering technique each.
3. Annotate both proposals with material and a specification point each meets.
4. Develop one proposal further and annotate what changed and why.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
