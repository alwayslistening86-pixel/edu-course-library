## Test items
1. Parent acquires 70% of Subsidiary for £380,000; at acquisition Subsidiary's identifiable net assets (fair value) are £600,000. Using the proportionate NCI method, calculate NCI at acquisition and goodwill, and comment on the sign of your goodwill figure. [5 marks]
2. Subsidiary (75% owned, acquired when its retained earnings were £180,000) now has retained earnings of £240,000. Calculate the amount added to consolidated retained earnings and the amount added to NCI in respect of this post-acquisition movement. [4 marks]
3. Subsidiary sells goods to Parent for £50,000 that cost Subsidiary £35,000; 60% remain in Parent's closing inventory. Subsidiary is 80% owned. Calculate the unrealised profit to eliminate, and explain how it is split between group retained earnings and NCI, naming which type of intra-group sale this is. [5 marks]
4. Which is/are true of a subsidiary under IFRS 10 full consolidation? Choose every correct option.
   A. 100% of the subsidiary's assets and liabilities are added to the parent's own, line by line
   B. Only the parent's ownership percentage of the subsidiary's assets is added
   C. The portion of the subsidiary not owned by the parent is shown as non-controlling interest
   D. Consolidation reflects control, not just ownership percentage

## Answer key (for the tutor only)
1. [5] M1 NCI at acquisition = 30% x 600,000 = £180,000; M1 goodwill = 380,000 + 180,000 - 600,000; A1 = -£40,000; B1 this is negative -- a 'bargain purchase' -- which under IFRS 3 is recognised immediately as a gain in profit or loss (after reassessing the fair values used) rather than as negative goodwill carried on the statement of financial position; B1 correct interpretation that a bargain purchase gain, while permitted, should prompt a careful re-check of the fair values used, since it is an unusual outcome.
2. [4] M1 post-acquisition increase = 240,000-180,000 = £60,000; M1 group share = 75% x 60,000; A1 = £45,000 added to consolidated retained earnings; A1 NCI share = 25% x 60,000 = £15,000 added to NCI.
3. [5] M1 profit on the sale = 50,000-35,000 = £15,000; M1 unrealised profit = 60% x 15,000 = £9,000; B1 this is an upstream sale (subsidiary is the seller); M1 the adjustment is split in the ownership ratio, since the unrealised profit arose in the subsidiary's own results, which NCI shares in: group share = 80% x 9,000 = £7,200; A1 NCI share = 20% x 9,000 = £1,800.
4. Correct: A, C, D (exactly these options, no others)
