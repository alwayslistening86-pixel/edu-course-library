## Test items
1. Standard hours allowed for actual output = 900 hours; actual hours worked = 840 hours; standard labour rate = £15.00/hour. Calculate the labour efficiency variance and state whether it is favourable or adverse. [3 marks]
2. Budgeted fixed overhead £120,000 for a budgeted output of 3,000 units; actual output was 3,250 units; actual fixed overhead was £119,000. Calculate the fixed overhead expenditure variance and the fixed overhead volume variance. [4 marks]
3. A material price variance is favourable (materials bought below standard price) but the usage variance for the same material is significantly adverse. Suggest one plausible explanation linking the two, and explain why investigating variances individually, without considering this link, can be misleading. [4 marks]
4. Which are genuine perspectives in Kaplan and Norton's balanced scorecard? Choose every correct option.
   A. Financial
   B. Customer
   C. Internal business process
   D. Shareholder dividend policy
5. Explain why a management accounting function might track ESG/sustainability KPIs (e.g. carbon emissions per unit produced) alongside traditional financial variances, rather than leaving this solely to a separate sustainability team. [3 marks]

## Answer key (for the tutor only)
1. [3] M1 efficiency variance = (900-840) x 15; A1 = £900; B1 favourable (fewer hours were needed than the standard allowed for the output achieved).
2. [4] M1 expenditure variance = 120,000 - 119,000 = £1,000 favourable (spent less than budgeted); M1 standard absorption rate = 120,000/3,000 = £40/unit; M1 volume variance = (3,250-3,000) x 40; A1 = £10,000 favourable (more units were produced than budgeted, so more fixed overhead was absorbed than budgeted).
3. [4] B2 plausible explanation: the purchasing department bought cheaper, lower-quality material (or from a less reliable supplier), producing a favourable price variance, but the lower-quality material caused higher wastage/rework in production, producing an adverse usage variance; B2 investigating each variance in isolation could wrongly reward purchasing for the favourable price variance and blame production for the adverse usage variance, when the true root cause is a single purchasing decision -- variances need to be read together, with the underlying cause investigated, not simply totted up department by department.
4. Correct: A, B, C (exactly these options, no others)
5. [3] B1 ESG performance increasingly affects financial outcomes directly -- e.g. regulatory costs (carbon taxes/reporting requirements), cost of capital (investors and lenders pricing in ESG risk), and reputational/customer-demand effects on revenue; B1 embedding ESG KPIs within the same internal reporting and variance-analysis framework as financial measures lets managers see trade-offs and connections (e.g. a process change that raises cost but cuts emissions) in one decision-relevant view, rather than in a disconnected separate report; B1 management accountants have the existing skill set (costing, KPI design, variance investigation) to build and maintain rigorous, decision-useful non-financial reporting systems.
