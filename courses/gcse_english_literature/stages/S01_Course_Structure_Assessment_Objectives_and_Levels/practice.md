# S01_Course_Structure_Assessment_Objectives_and_Levels - Practice: How the qualification is assessed: Papers 1 and 2, the four assessment objectives, weightings and the levels-of-response ladder

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Without looking, write down the marks and timing for both papers from memory, then check against the lesson.
2. Match each of these sentence starters to the AO it best represents: 'This suggests that...', 'The writer uses a metaphor here to...', 'This reflects the period's belief that...', 'The essay is grammatically accurate and varied.'
3. Explain in one sentence why AO4 is only worth 5% overall but still worth checking for.
4. Describe, in your own words, the difference between a Level 3 and a Level 5 response on the six-level ladder.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
