# S02_Core_Literary_Essay_Skills - Practice: The transferable skills every literature essay needs: quotation, language analysis, structure analysis, context, comparison, planning and accuracy

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Take the claim 'Scrooge is unpleasant' and rewrite it using the point-plus-proof pattern from 3.3.1, inventing a short, plausible quotation.
2. Analyse one invented line of dialogue ('Go away,' he said, turning his back) for language, then for structure (where it might sit in a scene), using the three-step method.
3. Write one sentence that uses context purposefully, following the 'because... presents... as...' pattern, about any historical period you know.
4. Write a four-point plan (one line each) for the essay question 'How is power presented?' using any text of your choice.
5. Find and correct three deliberately inserted spelling errors in a short paragraph your tutor gives you.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
