# S06_Living_the_Christian_Life_Worship_and_Devotion - Practice: Living the Christian life: worship, sacraments, prayer and pilgrimage

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Explain one difference between liturgical and non-liturgical worship.
2. Explain the Catholic and typical Protestant understandings of the Eucharist.
3. Explain the difference between set and informal prayer, with an example of when each might be used.
4. Name two Christian pilgrimage sites and explain why Christians disagree about pilgrimage's importance.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
