# S01_How_the_Qualification_Works - Practice: How GCSE Religious Studies B works: papers, assessment objectives and technique

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. State the timing and marks for each paper, and how many questions each paper has.
2. In your own words, explain the difference between AO1 and AO2.
3. Explain where the SPaG marks are located and how many marks they add.
4. Explain what 'non-religious worldview' means and give two examples.
5. Match each command word (give, explain two, explain two contrasting, discuss) to the number of marks and type of answer it needs.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
