# S03_Core_Perspectives_Key_Concepts_and_Sociological_Skills - Practice: The four core perspectives (functionalism, Marxism, feminism, interactionism), further key concepts, and evaluating, interpreting and applying sociology to contemporary issues

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Summarise the core claim of each of the four perspectives in one sentence each.
2. Give an original example of labelling leading to a possible self-fulfilling prophecy.
3. Explain the difference between power and authority, with an example of each.
4. Read a short described sociological data extract (for example, a statistic on family type) and explain what point it supports.
5. Choose a current social issue and explain how a sociologist might question the 'common sense' view of it.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
