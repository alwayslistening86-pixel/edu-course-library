# S20_Data_Types_Sources_Interpretation_and_Practical_Ethical_Issues - Practice: Research methods: qualitative/quantitative and official/non-official data, primary/secondary sources, interpreting data, and practical and ethical issues

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Explain the difference between qualitative and quantitative data, with an example of each.
2. Explain one strength and one weakness of official statistics compared with non-official statistics.
3. Explain the difference between primary and secondary data, giving an original example of each.
4. Interpret a described data table or graph, stating the pattern shown using specific figures.
5. Explain one practical issue and one ethical issue that could affect a study using covert observation.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
