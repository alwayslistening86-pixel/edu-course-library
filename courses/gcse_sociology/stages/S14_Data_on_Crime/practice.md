# S14_Data_on_Crime - Practice: Data on crime: sources, patterns and trends, the dark figure, and evaluating official statistics

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Name and briefly describe the three main sources of crime data covered in this specification.
2. Explain the dark figure of crime, giving one reason it exists.
3. Give one example of a genuine change in crime versus a statistical artefact (a change caused by recording or policing practice rather than real behaviour).
4. Write a short, balanced evaluation of the reliability of official crime statistics.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
