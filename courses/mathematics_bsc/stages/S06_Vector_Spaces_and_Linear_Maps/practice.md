# S06_Vector_Spaces_and_Linear_Maps - Practice: Vector spaces and linear maps

## Goal
Low-stakes practice: the learner attempts each question or proof in full before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Determine whether {(1,1,0),(0,1,1),(1,0,1)} is a basis of R^3. [4 marks]
2. Find the matrix of T: R^2 -> R^2, T(x,y)=(3x-y, x+2y), with respect to the standard basis, and find T(2,-1). [3 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [4] M1 forms the 3x3 matrix and computes its determinant; A1 det = 1(1-0)-1(0-1)+0 = 2, nonzero; A1 so the vectors are linearly independent; A1 three independent vectors in a 3-dim space form a basis.
2. [3] M1 columns T(1,0)=(3,1), T(0,1)=(-1,2); A1 matrix [[3,-1],[1,2]]; A1 T(2,-1)=(3(2)-(-1), 2+2(-1))=(7,0).

## How to run it
One question at a time. Let the learner finish an attempt (including a full proof, not just an answer) before offering a hint; then walk through the model solution and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
