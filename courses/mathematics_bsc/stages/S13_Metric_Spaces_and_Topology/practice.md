# S13_Metric_Spaces_and_Topology - Practice: Metric spaces and topology

## Goal
Low-stakes practice: the learner attempts each question or proof in full before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Verify the triangle inequality holds for d(x,y)=|x-y| on R using three specific numbers, e.g. x=1,y=5,z=8. [3 marks]
2. Is [2,5) open, closed, both or neither in R with the usual metric? [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] M1 d(1,8)=7; A1 d(1,5)+d(5,8)=4+3=7; A1 7<=7, triangle inequality holds (with equality here since 5 lies between 1 and 8).
2. [2] M1 tests point 2: no ball around 2 stays inside (not open); A1 tests convergent sequence 5-1/n -> 5, not in the set (not closed); neither open nor closed.

## How to run it
One question at a time. Let the learner finish an attempt (including a full proof, not just an answer) before offering a hint; then walk through the model solution and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
