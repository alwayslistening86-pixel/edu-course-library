# S15_The_Computing_and_IT_Project - Practice: The computing and IT project: methodology and practice

## Goal
Low-stakes practice: the learner attempts each question, trace or piece of code in full before seeing the solution. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Give one reason an unbounded project scope is a serious risk in a fixed-length individual project. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 without a clear boundary on what will and will not be attempted, the work can expand indefinitely (scope creep); B1 this risks running out of time before any part of the project is finished to a usable/evaluable standard, since effort is spread across an ever-growing set of goals rather than concentrated on completing a bounded, well-defined piece of work.

## How to run it
One question at a time. Let the learner finish a genuine attempt (including full working for a trace or calculation) before offering a hint; then walk through the model solution/actual output and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
