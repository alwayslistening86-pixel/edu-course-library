# S12_FA_Trial_Balance_and_Extended_Trial_Balance - Practice: The initial trial balance, the adjusted trial balance and the extended trial balance

## Goal
Low-stakes practice: the learner works each calculation or entry in full before checking the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Which of these errors would NOT be disclosed by a trial balance (it would still balance)? Choose every correct option.
   A. A transaction posted to the wrong account of the correct type (error of commission)
   B. A trial balance where one figure was simply left off entirely from only one column
   C. A debit entry made with no corresponding credit entry
   D. Posting an amount to only one side of the ledger
2. On an ETB, the statement of profit or loss columns total: debit £46,000, credit £39,000. Calculate the profit or loss for the period, stating which it is. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: A (exactly these options, no others)
2. [2] M1 debit exceeds credit by 46,000 - 39,000 = £7,000; A1 this is a loss of £7,000 for the period.

## How to run it
One item at a time. Let the learner finish a full attempt (workings shown) before revealing the answer; walk through any step they got wrong.

## When to move to test
When the learner gets a new item of each type right without prompting.
