# S22_MA_Spreadsheet_Techniques - Practice: Spreadsheet techniques for management accounting information

## Goal
Low-stakes practice: the learner works each calculation or entry in full before checking the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Which spreadsheet function would best total the cost of only the rows relating to one named cost centre in a large dataset? Choose every correct option.
   A. SUMIF
   B. VLOOKUP
   C. IF
   D. SORT
2. State one use of a pivot table in preparing management accounting information. [1 mark]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: A (exactly these options, no others)
2. [1] B1 any reasonable use, e.g. quickly summarising/cross-tabulating a large dataset (e.g. total cost by cost centre and month) without writing a separate formula for every combination.

## How to run it
One item at a time. Let the learner finish a full attempt (workings shown) before revealing the answer; walk through any step they got wrong.

## When to move to test
When the learner gets a new item of each type right without prompting.
