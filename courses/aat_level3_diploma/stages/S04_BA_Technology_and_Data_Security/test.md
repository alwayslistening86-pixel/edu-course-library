# S04_BA_Technology_and_Data_Security - Test: New technologies in accounting and data protection/security

## How to run this
A real checkpoint in AAT's own style: numeric gap-fill calculations, journal/ledger-entry and financial-statement questions and multiple-choice items, with marks shown. Give the whole test at once, with no hints and a calculator allowed (as in the real assessment). Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Explain how outsourcing a payroll function might affect a business's cost structure and access to expertise. [3 marks]
2. Which is an example of a cybersecurity threat? Choose every correct option.
   A. Phishing
   B. A firewall
   C. Data minimisation
   D. Purpose limitation
3. Explain the potential impact of a data breach on (a) an affected individual and (b) the business responsible. [2 marks]
4. Describe two ways an organisation can protect its information systems from unauthorised access. [2 marks]

## Answer key (for the tutor only)
1. [3] B1 outsourcing can reduce cost by using a specialist provider's economies of scale rather than employing in-house staff; B1 it can give access to expertise the business does not have internally (e.g. up-to-date payroll legislation knowledge); B1 but it introduces reliance on an external party and reduces direct day-to-day control.
2. Correct: A (exactly these options, no others)
3. [2] B1 (a) individual, e.g. identity theft, financial loss or distress; B1 (b) business, e.g. regulatory fine, reputational damage, loss of customer trust or legal claims.
4. [2] B1 restricting access levels so staff only see data needed for their role; B1 using firewalls to block unauthorised network access; B1 integrity controls to detect if data has been tampered with; B1 cybersecurity measures against cyberattacks -- any 2 for full marks.
