# S04_BA_Technology_and_Data_Security - Practice: New technologies in accounting and data protection/security

## Goal
Low-stakes practice: the learner works each calculation or entry in full before checking the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Which GDPR principle requires personal data to be kept no longer than necessary? Choose every correct option.
   A. Storage limitation
   B. Data minimisation
   C. Purpose limitation
   D. Accountability
2. State one benefit and one limitation of cloud accounting software. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: A (exactly these options, no others)
2. [2] B1 benefit, e.g. remote access/real-time data/collaboration; B1 limitation, e.g. dependence on internet connection, ongoing subscription cost, or data security concerns.

## How to run it
One item at a time. Let the learner finish a full attempt (workings shown) before revealing the answer; walk through any step they got wrong.

## When to move to test
When the learner gets a new item of each type right without prompting.
