# S27_TAX_VAT_Calculations_and_Returns - Practice: Calculating VAT and preparing/submitting the VAT return

## Goal
Low-stakes practice: the learner works each calculation or entry in full before checking the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. A business has standard-rated sales (excl VAT) of £30,000 and standard-rated purchases (excl VAT, all recoverable) of £12,000 in a VAT period. Calculate the VAT payable to HMRC. [3 marks]
2. Which of these input VAT costs is generally NOT recoverable? Choose every correct option.
   A. Client entertaining
   B. Standard-rated stock purchases
   C. Standard-rated office supplies
   D. Standard-rated equipment purchases

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] M1 output VAT = 30,000 x 20% = £6,000; M1 input VAT = 12,000 x 20% = £2,400; A1 VAT payable = £3,600.
2. Correct: A (exactly these options, no others)

## How to run it
One item at a time. Let the learner finish a full attempt (workings shown) before revealing the answer; walk through any step they got wrong.

## When to move to test
When the learner gets a new item of each type right without prompting.
