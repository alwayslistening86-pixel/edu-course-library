# S18_MA_Materials_Costing - Practice: Materials costing: FIFO, LIFO and AVCO

## Goal
Low-stakes practice: the learner works each calculation or entry in full before checking the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Opening inventory 50 units @ £10.00 = £500. A receipt of 100 units @ £11.00 = £1,100 follows (150 units, £1,600 total). Using AVCO, calculate the weighted average cost per unit after this receipt. [2 marks]
2. In a period of falling prices, which method gives the highest closing inventory valuation? Choose every correct option.
   A. LIFO
   B. FIFO
   C. AVCO
   D. All three are identical

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] M1 1,600/150; A1 = £10.67 per unit (to the nearest penny).
2. Correct: A (exactly these options, no others)

## How to run it
One item at a time. Let the learner finish a full attempt (workings shown) before revealing the answer; walk through any step they got wrong.

## When to move to test
When the learner gets a new item of each type right without prompting.
