# S18_MA_Materials_Costing - Test: Materials costing: FIFO, LIFO and AVCO

## Test items
1. Opening inventory: 80 units @ £4.00 = £320. Receipt: 120 units @ £4.50 = £540 (200 units total). 150 units are then issued. Using FIFO, calculate the cost of the issue and the value of the closing inventory. [4 marks]
2. Using the same opening inventory (80 units @ £4.00 = £320) and receipt (120 units @ £4.50 = £540), and the same issue of 150 units, calculate the issue cost and closing inventory value using LIFO instead. [4 marks]
3. Why is LIFO not used for external financial reporting, even though AAT still requires it as a costing technique? Choose every correct option.
   A. It is not permitted under UK/international financial reporting standards
   B. It always gives the same answer as FIFO
   C. It cannot be calculated by hand
   D. It is only used for services, not goods
4. Explain the effect on reported profit of using FIFO rather than LIFO in a period of rising prices. [3 marks]

## Answer key (for the tutor only)
1. [4] M1 issue: 80 @ £4.00 = £320, plus 70 @ £4.50 = £315 (150 units used); A1 issue cost = 320 + 315 = £635; M1 remaining inventory = 50 units @ £4.50; A1 closing inventory = £225.
2. [4] M1 issue: 120 @ £4.50 = £540, plus 30 @ £4.00 = £120 (150 units used); A1 issue cost = 540 + 120 = £660; M1 remaining inventory = 50 units @ £4.00; A1 closing inventory = £200.
3. Correct: A (exactly these options, no others)
4. [3] B1 FIFO values closing inventory at the most recent (higher) prices, giving a higher closing inventory value and lower cost of sales than LIFO; B1 LIFO values issues at the most recent (higher) prices, giving a higher cost of sales and lower closing inventory value; B1 so FIFO reports the higher profit of the two in a period of rising prices.
