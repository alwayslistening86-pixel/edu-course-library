#### MA3.1 Marginal vs absorption costing: preparing statements under each method, and reconciling the difference in reported profit
**Marginal costing** treats only **variable** production costs (materials, labour, variable overhead) as the cost of a unit; all **fixed costs** (including fixed production overhead) are treated as a **period cost**, charged in full against the profit of the period they are incurred in. **Absorption costing** treats fixed production overhead as part of the **unit cost** too, absorbed into each unit produced using an OAR (S19) -- so some fixed production overhead is carried forward in closing inventory rather than all being charged against the current period. The two methods therefore only give a **different profit figure** when opening and closing inventory levels differ (i.e. production does not exactly equal sales); if production equals sales in every period, they give the same profit. When **production exceeds sales** (inventory increases), absorption costing defers some fixed overhead into closing inventory, so it reports a **higher** profit than marginal costing that period; when **sales exceed production** (inventory decreases), absorption costing releases previously deferred fixed overhead from opening inventory, so it reports a **lower** profit. **Marginal costing** is often preferred for short-term decision-making (S23), since it clearly separates variable cost/contribution from fixed cost; **absorption costing** is required for external financial reporting under IAS 2, since it matches all production cost (fixed and variable) to the units it relates to. *Worked example:* selling price £50/unit, variable cost £30/unit, budgeted/actual fixed production overhead £4,000 for budgeted output of 1,000 units (OAR = £4/unit), fixed selling and administration costs £2,000. 1,000 units are produced and 900 sold (closing inventory 100 units). **Marginal costing:** contribution = 900 x (50-30) = £18,000; less fixed costs (4,000 + 2,000) = £6,000; profit = **£12,000**. **Absorption costing:** cost of sales = 900 x (30+4) = £30,600; gross profit = 45,000 - 30,600 = £14,400; less fixed selling/admin £2,000; profit = **£12,400**. **Reconciliation:** the £400 difference (12,400 - 12,000) equals the fixed overhead carried forward in the 100 extra closing inventory units: 100 x £4 (the fixed OAR) = **£400**.
