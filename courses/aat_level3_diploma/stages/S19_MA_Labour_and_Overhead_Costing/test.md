## Test items
1. An employee's basic rate is £16.50/hour, standard week 38 hours. They work 44 hours, with hours beyond 38 paid at time and a half. Calculate their basic pay, overtime pay and total gross pay. [4 marks]
2. Heating costs of £15,000 are apportioned between two cost centres by floor volume: Centre X 12,000 cubic metres, Centre Y 8,000 cubic metres. Calculate each centre's share. [3 marks]
3. A cost centre's OAR is £8.00 per labour hour, based on budgeted activity. Actual labour hours worked were 5,600, and actual overhead incurred was £45,500. Calculate the overhead absorbed and state whether the cost centre has an under- or over-absorption, and by how much. [4 marks]
4. Which of these is correctly described as an allocated (not apportioned) overhead? Choose every correct option.
   A. A production department's own supervisor's salary, charged wholly to that department
   B. Rent, shared between departments by floor area
   C. Building insurance, shared between departments by asset value
   D. Heating, shared between departments by volume
5. Explain why an overhead absorption rate, calculated from budgeted figures, will rarely absorb exactly the overhead actually incurred. [2 marks]

## Answer key (for the tutor only)
1. [4] M1 basic pay = 38 x 16.50 = £627.00; M1 overtime hours = 44 - 38 = 6, overtime rate = 16.50 x 1.5 = £24.75; A1 overtime pay = 6 x 24.75 = £148.50; A1 total gross pay = 627.00 + 148.50 = £775.50.
2. [3] M1 total volume = 12,000 + 8,000 = 20,000; M1 X's share = 15,000 x 12,000/20,000 = £9,000; A1 Y's share = 15,000 x 8,000/20,000 = £6,000.
3. [4] M1 overhead absorbed = 5,600 x 8.00 = £44,800; M1 compare to actual incurred £45,500; A1 absorbed (£44,800) is less than incurred (£45,500); B1 under-absorption of £700.
4. Correct: A (exactly these options, no others)
5. [2] B1 the OAR is set in advance using budgeted overhead and budgeted activity level; B1 actual overhead incurred and/or actual activity level will normally differ from budget, so the overhead absorbed (OAR x actual activity) will not exactly equal the overhead actually incurred, causing under- or over-absorption.
