# S28_TAX_Documentation_and_Communication - Practice: Using tax documentation and legislation, and communicating VAT/tax information

## Goal
Low-stakes practice: the learner works each calculation or entry in full before checking the model answer. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Where should an accountant check for the current UK VAT rates and thresholds? Choose every correct option.
   A. gov.uk
   B. A textbook from several years ago
   C. Social media
   D. Memory of rates learned previously
2. State one reason using out-of-date tax information could cause a problem for a business. [1 mark]

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: A (exactly these options, no others)
2. [1] B1 any reasonable reason, e.g. a VAT return could be calculated using the wrong rate/threshold, leading to an under- or over-payment and possible penalties.

## How to run it
One item at a time. Let the learner finish a full attempt (workings shown) before revealing the answer; walk through any step they got wrong.

## When to move to test
When the learner gets a new item of each type right without prompting.
