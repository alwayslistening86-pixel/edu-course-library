# S01_What_Is_Java_and_Java_Basics - Practice: What Java is, and the basics of a Java program

## Goal
Low-stakes practice: the learner predicts or writes first, then runs it to check. Mistakes are expected and corrected here, before any grading.

## Practice items
1. Which tool turns Hello.java into Hello.class? Choose every correct option.
   A. `javac`
   B. `java`
   C. `jar`
   D. the JVM
2. Write a complete program in a file called Greet.java that prints `Hi, ` followed by its first command-line argument, and give the two commands to compile and run it with the argument Sam.

## Answers (for the tutor; reveal only after a genuine attempt)
1. Correct: A (exactly these options, no others)
2. The tutor runs or reads the learner's answer and checks: a public class Greet with a correct main signature; prints "Hi, " + args[0]; commands `javac Greet.java` then `java Greet Sam`.

## How to run it
One item at a time. For output questions the learner commits to a prediction before running anything. Offer a worked explanation only after an attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
