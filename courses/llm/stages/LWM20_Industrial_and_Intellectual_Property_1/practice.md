# LWM20_Industrial_and_Intellectual_Property_1 - Practice: Industrial and Intellectual Property A-B — Patents, trade secrets and copyright

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Apply the Aerotel/Macrossan test to a claimed invention that is a new algorithm for compressing data, run entirely in software with no new hardware.
2. Evaluate whether a start-up should protect a novel manufacturing process by patent or trade secret, given a competitor could plausibly reverse-engineer the product within 18 months.
3. Evaluate whether Infopaq's "author's own intellectual creation" standard should still be treated as binding in a case decided by the Court of Appeal in 2026.
4. Apply the substantial-part test and the fair dealing defences to a critical book review that reproduces three short passages from a copyrighted novel.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
