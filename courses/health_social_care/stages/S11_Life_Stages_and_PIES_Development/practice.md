# S11_Life_Stages_and_PIES_Development - Practice: R033 life stages, milestones and PIES development

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Create a two-column table (age range against a milestone you would expect) for all five life stages. Check it against a peer or book and correct any errors.
2. For a fictional 14-year-old, describe (in four short paragraphs) what PIES development you would expect. Then underline the specific details that make it about her, not everyone.
3. Explain the difference between fine and gross motor skills with two examples each and say in which life stage each becomes more difficult again.
4. In your own words, explain what would make a description of development 'brief' rather than 'comprehensive'.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
