# S10_R032_Exam_Technique - Practice: R032 exam technique: paper structure, command words and extended answers

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write a one-mark answer, a two-mark answer and a three-mark answer for: 'Identify/explain/explain how a hospital protects service users from infection.'
2. Write a six-mark answer (Level 3 style) to: 'Explain how two person-centred values could be applied by a carer looking after a resident with dementia.'
3. Write an eight-mark answer to: 'Discuss the impact of effective communication on a patient newly diagnosed with diabetes.' Then mark it against the level descriptors above.
4. Rewrite this weak sentence so that it scores: 'The nurse should be nice to him.' Use a value, an action and an effect.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
