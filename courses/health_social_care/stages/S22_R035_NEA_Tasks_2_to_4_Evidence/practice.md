# S22_R035_NEA_Tasks_2_to_4_Evidence - Practice: R035 Task 2 to 4 evidence: planning, delivering and evaluating the campaign for assessment

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write what a 'basic' plan (MB1) might look like for one strand (for example resources) compared with a 'comprehensive' version (MB3) for the same strand.
2. Explain the difference between a 'simple' and a 'complex' campaign delivery in your own words, with an example of each.
3. Write one piece of specific evidence (a feedback comment or an observed detail) that would support a strength claimed for 'engagement'.
4. Turn a vague improvement suggestion ('be better next time') into a detailed, justified one using invented but plausible feedback.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
