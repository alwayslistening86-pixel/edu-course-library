# S03_Person_Centred_Values_and_the_6Cs - Practice: Person-centred values and the 6Cs

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write one specific example of how a physiotherapist in a hospital could apply each of: independence, dignity, partnership.
2. Define each of the 6Cs in one sentence and give one care-home example for compassion and courage.
3. A carer in a residential home always calls a Sikh resident by his first name without asking and says his turban is 'in the way'. Which person-centred values are not applied, and which of the 6Cs might the carer lack?
4. Choose any two person-centred values and explain how they overlap.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
