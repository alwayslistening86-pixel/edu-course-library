# S12_R093_Exam_Structure_and_Technique - Practice: R093 exam structure, command words and extended responses

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Rewrite the answer 'a mood board is a collage' so that it answers the command word Explain for a scenario about a cafe brand.
2. Take a Section A style question ('Which of these is a lossless format? PNG, JPEG, MP3, MP4') and say how you would eliminate wrong answers and check with a definition.
3. Read a made-up scenario about a school open-day film and underline five details you should use in an answer.
4. Write a 5-point plan (not the full answer) for: 'Evaluate the importance of client requirements when planning the film.'

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
