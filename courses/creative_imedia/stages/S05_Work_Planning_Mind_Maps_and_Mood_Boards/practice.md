# S05_Work_Planning_Mind_Maps_and_Mood_Boards - Practice: Work planning, mind maps and mood boards

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Name eight workplan components and give an example of a milestone and a contingency for a school-leavers' promotional video.
2. Explain two advantages of using a workplan for a team of five compared with working without one.
3. A designer must decide between a mind map and a mood board to (a) explore content ideas for a website and (b) agree a look and feel with a client. Which is appropriate for each and why?
4. A mood board for a children's game contains dark grey, sharp black-and-white photographs. Explain two ways to make it more effective.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
