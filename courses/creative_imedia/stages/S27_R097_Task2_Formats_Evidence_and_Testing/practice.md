# S27_R097_Task2_Formats_Evidence_and_Testing - Practice: Justifying formats for Task 2, and testing the finished product

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. List three checks you would run to confirm strand 2b's "fully working, consistent product" standard is met.
2. Write a justification for choosing a compressed image format over an uncompressed one for a website asset.
3. Draft a four-row test plan (feature, expected result, actual result, pass/fail) for an app you know.
4. Explain why testing before writing up "actual results" for a test plan is stronger evidence than writing the plan afterwards to match what happened.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
