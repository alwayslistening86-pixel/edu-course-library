# S29_J834_Qualification_Structure_Grading_and_NEA_Rules - Practice: The J834 qualification as a whole: structure, performance objectives, grading and NEA rules

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. State J834's unit structure, GLH per unit and the terminal assessment rule in your own words.
2. Match each performance objective (PO1-PO4) to a stage or strand from this course that assesses it.
3. Given example unit UMS scores of 70, 45 and 60, calculate the total and state the resulting overall grade.
4. Give one example of acceptable teacher feedback and one example of unacceptable feedback on the same NEA task.
5. Explain how one R093 topic area supports a named R094 or R097 strand.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
