# S11_Moving_Image_Files_and_File_Compression - Lesson: Moving image files and file compression

## Goal
The learner explains frame rate, resolution names, video and animation formats and lossy and lossless compression, and chooses suitable formats for use and context.

## Syllabus items taught here
- R093-4.2.3 - Moving image file properties and formats: explain frame rate, resolution names (SD to 8K), video and animation formats and when to use each
- R093-4.2.4 - Lossy and lossless file compression: define lossy and lossless compression and explain why each is used

## How to teach this
Ask: 'Why does a streamed film sometimes go blurry and then sharp again?' Then draw a flick book on paper to show that video is a fast sequence of still frames.

#### R093-4.2.3 Moving image file properties and formats
Frame rate is the number of frames shown per second (fps). Film is traditionally 24 fps, European television 25, and 30 or 60 fps are common online and in games. A higher frame rate looks smoother but needs more storage and processing; a low frame rate looks jerky. Resolution describes frame size: SD (standard definition, about 720 x 576), HD (720p or 1080p, for example 1920 x 1080), UHD/4K (about 3840 x 2160) and 8K (about 7680 x 4320). More pixels give more detail and bigger files and need more bandwidth. Video formats include MP4, MOV, AVI, WMV and MKV; animation formats include GIF and formats from animation software, and video export formats for finished animations. Uncompressed video is enormous, so most distribution files are compressed. Choose by context: a compressed MP4 for streaming on mobiles, a high-quality MOV or lightly compressed master for editing, an animated GIF for a short looping web graphic. Limitations include compatibility with players and the loss of quality when lossy compression is heavy.

#### R093-4.2.4 Lossy and lossless file compression
Compression reduces file size so that files store and transmit more easily. Lossy compression permanently removes some data, typically detail that is hard to notice, to get a much smaller file; examples are JPEG, MP3 and most video formats. Each time a lossy file is edited and re-saved quality can fall further, so keep a master. Lossless compression reduces size without losing any data, so the original can be rebuilt exactly; examples are PNG, FLAC and ZIP. Reasons: lossy is used where small size matters more than perfect quality (web, streaming, mobile); lossless is used where accuracy matters (master copies, logos and text-heavy graphics, archives). The exam asks learners to know what each means and why each is used, and to say which suits a situation, so always give the trade-off: quality against file size.
