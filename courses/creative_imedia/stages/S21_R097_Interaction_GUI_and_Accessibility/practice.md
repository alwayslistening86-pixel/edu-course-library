# S21_R097_Interaction_GUI_and_Accessibility - Practice: Methods of interaction, GUI design, interface styles and accessibility

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. List the five interaction methods and match each to a device or context where it suits best.
2. Sketch a simple three-button GUI for a "book a class" screen, labelling colour scheme, typography choice and where white space is used.
3. Compare menu-driven and form-based interface styles and give an example use for each.
4. Choose two accessibility features for an e-learning product aimed at adult learners and justify each.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
