## Test scenario
Practice brief (original): 'An e-learning app teaching basic first aid to adult learners, some of whom have limited reading confidence and some of whom use screen readers.' a) Recommend a suitable interaction method for the main lesson screens and justify it (4). b) Describe the GUI you would design, covering layout, colour scheme and typography (6). c) Choose three accessibility features this audience needs and justify each (9). This tests understanding, not a finished interface.
