# S19_Saving_Exporting_and_Task_2_Evidence - Lesson: Saving, exporting and evidencing Task 2

## Goal
The learner keeps high-resolution master files, exports visual identity and graphics in formats and properties that meet client requirements, and knows how to evidence every Task 2 strand independently.

## Syllabus items taught here
- R094-3.3 - Saving and exporting visual identity and digital graphics: keep a high-resolution master file and export copies in formats and properties that meet client requirements
- R094-T2a - Task 2 strand 2a: creating and saving the visual identity: know how to evidence effective technical skills and appropriate properties and format for the visual identity
- R094-T2b - Task 2 strand 2b: preparing assets: know how to show explicit, all-asset preparation before creating the graphic
- R094-T2c - Task 2 strand 2c: creating the digital graphic: know how to evidence tools, design concepts, layout conventions and client fit
- R094-T2d - Task 2 strand 2d: saving and exporting the finished graphics: know how to choose and evidence correct properties and formats for both required outputs

## How to teach this
Ask: 'The client wants one file for print and one for a web banner. What would you save and how would you prove your choices were deliberate?' Use a practice brief only. In the real assessment the learner decides the tools, techniques, formats and properties independently; the tutor may only remind them of teaching content.

#### R094-3.3 Saving and exporting visual identity and digital graphics
Save a high-resolution master file in the software's proprietary format (for example a layered file) as an archive for further edits: it keeps layers, text and settings. Then repurpose and export copies in file formats and image properties that meet the client's requirements: for print a high-resolution PDF or TIFF/PNG or JPEG at 300 dpi at the required size; for web a lower-resolution PNG (for transparency) or JPEG at screen pixel dimensions, with sensible compression. Name exports clearly (client_product_use). Do not overwrite the master. Check the exported file by opening it. Evidence: screenshots of the Save As or Export dialog with settings, plus a folder view.

#### R094-T2a Task 2 strand 2a: creating and saving the visual identity
Strand 2a (6 marks) has two parts: use of technical skills to create the visual identity (limited, adequate or effective) and properties and format(s) of the identity (limited, adequate or clearly appropriate). Technical skill is judged qualitatively: precision, accuracy and overall effectiveness in creating the identity. For the upper bands the exported identity must be suitable for further use in graphic design products, for instance a transparent-background version at good resolution. Unsuitable properties combined with unsuitable formats can only earn MB1; both must be appropriate for MB3. Learners should create the identity in software (not a hand drawing) and show the process in annotated screenshots.

#### R094-T2b Task 2 strand 2b: preparing assets
Strand 2b (6 marks) has two parts. Quantity: few, some or all assets prepared for the digital graphic. This must be clearly and explicitly evidenced as a preliminary activity before creating the graphic; if preparation is merely implied, MB1 is appropriate. For MB3 all assets are prepared at a suitable resolution. Quality: effectiveness of the technical skills in preparing assets, judged by whether the dimensions, resolution and file format are suitable, supported by explicit evidence. Method: make a preparation table (asset, original size, changes, final size, format) with screenshots.

#### R094-T2c Task 2 strand 2c: creating the digital graphic
Strand 2c (12 marks) has three descriptors. Use of tools and techniques (limited, partly effective, effective): the degree to which the learner is effective in using the tools and techniques, not the overall quality of the finished graphic; for high marks they must evidence skills in applying the tools and techniques in the teaching content. Design concepts and layout conventions (limited, adequate, effective): the overall look and feel, alignment, typography, colour, white space, layout conventions for the product and the placement and inclusion of the visual identity. Client requirements (limited, adequate, fully): synergy between what the client wanted, the style of the visual identity and the content and layout. Students decide independently and must not be told which tools to use.

#### R094-T2d Task 2 strand 2d: saving and exporting the finished graphics
Strand 2d (6 marks) is about saving and exporting the finished graphic in the two formats required by the scenario. Image properties and file format both need to be correct in both files for the upper band. Best-fit marking takes both versions into account: if one is clearly inappropriate, MB2 is the highest possible. Learners decide independently. Evidence: export settings, file properties (dimensions, dpi, file type, size) for both files, and a short explanation of why the choices suit each use (print needs high resolution and CMYK-suitable output, web needs smaller pixel dimensions and compression).

## Explicitly not here
Mark-scheme moderation and grading arithmetic (S30).
