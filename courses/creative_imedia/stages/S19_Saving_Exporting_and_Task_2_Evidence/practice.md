# S19_Saving_Exporting_and_Task_2_Evidence - Practice: Saving, exporting and evidencing Task 2

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Save a practice graphic as a layered master and as two exports (print and web). Record the settings for each.
2. Open both exports and check their dimensions and file sizes. State whether each meets the practice brief.
3. Draw up a preparation table of five assets with original and final sizes and formats.
4. Explain what would put strand 2d at MB2 at best even if the web export was excellent.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
