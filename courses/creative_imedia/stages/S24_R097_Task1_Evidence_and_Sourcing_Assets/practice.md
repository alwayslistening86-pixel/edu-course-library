# S24_R097_Task1_Evidence_and_Sourcing_Assets - Practice: Evidencing Task 1 in full, and sourcing assets for creation

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. List the three ways assets can be sourced (feature, property, licence) with an example search for each.
2. Explain why saving a sourced asset at the wrong resolution causes problems later.
3. Describe two repurposing techniques you would apply to a stock photo before using it in a product.
4. Write a short paragraph of planning documentation for one screen, covering layout, navigation and assets, that would meet strand 1b's "every element" requirement.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
