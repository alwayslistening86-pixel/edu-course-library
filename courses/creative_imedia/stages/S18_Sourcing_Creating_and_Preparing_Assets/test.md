# S18_Sourcing_Creating_and_Preparing_Assets - Test: Sourcing, creating, preparing and storing assets

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Practice task: 'Prepare four assets (two photographs, one graphic and one logo) for a printed A5 flyer for Ridgeway Bikes. Show the source, licence note, the preparation you carried out on each asset (size, resolution, format) and where you stored originals and edited copies.' Graded on completeness (all assets prepared), explicit evidence of preparation before building, and technical suitability.

## Grading
Apply `rubric.json`'s `stage_rubrics.S18_Sourcing_Creating_and_Preparing_Assets` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.
