# S18_Sourcing_Creating_and_Preparing_Assets - Practice: Sourcing, creating, preparing and storing assets

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Source three images for a Fernhill Bakery leaflet using search filters. Record URL, licence and size in an asset table.
2. Edit one sourced image into a derivative asset (crop, retouch, change colour) and show before and after.
3. A leaflet image will print 10 cm wide at 300 dpi. Work out the pixel width needed (about 1181 pixels) and check whether your source is large enough.
4. Set up a folder structure with originals and edited assets, and explain your naming convention.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
