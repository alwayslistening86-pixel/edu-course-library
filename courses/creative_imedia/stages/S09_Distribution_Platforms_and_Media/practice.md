# S09_Distribution_Platforms_and_Media - Practice: Distribution platforms and media

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Sort into online, physical platform or physical media: an app, a kiosk, a DVD, a website, a memory stick, a leaflet, interactive TV, a tablet.
2. Give one advantage and one disadvantage of distributing a short film on DVD and on the web.
3. A tourist information point in a station must show a map and short videos. Explain why a kiosk suits it and one drawback.
4. Explain how designing for a small mobile screen with limited data would affect the file format and size of images and video.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
