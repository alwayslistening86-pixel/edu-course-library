# S09_Distribution_Platforms_and_Media - Lesson: Distribution platforms and media

## Goal
The learner describes online platforms, physical platforms and physical media, weighs their advantages and disadvantages, and explains how platform characteristics affect the file format of a finished product.

## Syllabus items taught here
- R093-4.1 - Distribution platforms and media: know online, physical platform and physical media options and how platform characteristics affect file format choice

## How to teach this
Ask: 'The same film trailer has to reach people on a phone, in a cinema foyer kiosk and on a DVD. What has to change for each, and what stays the same?'

#### R093-4.1 Distribution platforms and media to reach audiences
The specification groups delivery methods. Online: apps, multimedia and the web. Physical platforms (devices on which products are viewed or used): computers, interactive TV, kiosks and mobile devices. Physical media (things that carry a product): CD/DVD, memory sticks and paper-based products. Each has characteristics. Web products reach a global audience instantly and can be updated, but need an internet connection and can be affected by bandwidth and file size. Apps can use device features such as the camera and work offline, but must be developed for each device type and approved by a store. Kiosks in public places offer touch interaction to passers-by but have limited screen time and fixed hardware. Mobile devices give portability but small screens and limited storage. CD/DVD and memory sticks work without internet and can be sold as objects, but are disappearing and have fixed capacity. Paper is cheap to hold and needs no power but is not interactive and cannot show moving images. Teach the link to file format: the platform's screen size, bandwidth, storage and software decide resolution, compression and format (a mobile web video needs a compressed file that streams quickly; a printed poster needs a high-resolution image).
