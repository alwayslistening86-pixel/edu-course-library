# S10_Image_and_Audio_File_Properties_and_Formats - Lesson: Image and audio file properties and formats

## Goal
The learner explains resolution, pixel dimensions, raster and vector, sample rate, bit depth and file formats for images and audio, and picks a suitable format for a use and context.

## Syllabus items taught here
- R093-4.2.1 - Image file properties and formats: explain DPI/PPI, pixel dimensions, raster and vector, and compressed and uncompressed image formats and when to use each
- R093-4.2.2 - Audio file properties and formats: explain sample rate, bit depth, compression and audio formats and when to use each

## How to teach this
Show the same photo enlarged until it goes blocky, and a vector logo enlarged with no loss. Ask: 'Why did one break and one not?' For audio, play a speech clip at very low quality and ask what has been lost.

#### R093-4.2.1 Image file properties and formats
Pixel dimensions are the width and height of an image in pixels (for example 1920 x 1080). DPI/PPI is dots or pixels per inch: how many are packed into each inch, so it relates to resolution and image quality; higher values give more detail but a bigger file. Screen use is typically 72 to 96 ppi; print typically needs about 300 dpi at the size it will be printed. A photograph that is 600 x 400 pixels looks fine on a small web page but poor as an A4 print because the pixels are spread thin. Raster (bitmap) images are grids of pixels (JPEG, PNG, GIF, BMP, TIFF); they lose quality when enlarged. Vector images are made of mathematical paths and shapes (SVG, AI, EPS); they scale without loss and suit logos and print, but are unsuitable for photographs. Uncompressed formats (BMP, TIFF) keep all data but are large; compressed formats reduce size by lossy (JPEG) or lossless (PNG, GIF) methods. PNG supports transparency; GIF is limited to 256 colours and can be animated. Format choice depends on use: JPEG for photos on the web, PNG for graphics needing transparency, vector for scalable logos, TIFF for print masters.

#### R093-4.2.2 Audio file properties and formats
Sample rate is how many times per second the sound is measured, in hertz: CD-quality is 44.1 kHz, video work often uses 48 kHz. A higher sample rate captures more detail and the file grows. Bit depth is how many bits store each sample: 16-bit for CD, 24-bit for studio recording; a higher bit depth gives more dynamic range and less noise, again with larger files. Together they decide sound quality and file size. Audio compression reduces file size: lossy compression removes detail the ear is less likely to notice (MP3, AAC, OGG) and cannot be reversed; lossless compression (FLAC) shrinks the file but can be restored exactly. Uncompressed formats such as WAV and AIFF keep everything and are used for editing and master copies. Choose by context: MP3 or AAC for streaming and phones, WAV for editing, a lower-quality voice file for a spoken podcast, and a high-quality file for music mastering.
