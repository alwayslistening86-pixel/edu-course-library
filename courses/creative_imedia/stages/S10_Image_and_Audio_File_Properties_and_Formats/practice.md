# S10_Image_and_Audio_File_Properties_and_Formats - Practice: Image and audio file properties and formats

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. A 1200 x 800 pixel image is printed 6 inches wide. Work out the ppi (200) and say whether it is good enough for a 300 dpi print, with a reason.
2. State one advantage and one limitation of vector images and of raster images.
3. Explain how sample rate and bit depth each affect quality and file size.
4. Recommend a format for each and give a reason: (a) a company logo for a shop sign and a website; (b) a photo on a news site; (c) the master copy of a music track; (d) a podcast for phones.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
