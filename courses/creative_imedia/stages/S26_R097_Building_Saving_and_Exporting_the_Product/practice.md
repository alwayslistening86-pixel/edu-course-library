# S26_R097_Building_Saving_and_Exporting_the_Product - Practice: Building the product and saving, exporting and publishing it correctly

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Describe the build order you would use for a four-screen product and why navigation should be tested as you go.
2. Explain why saving only a final version, with no earlier versions, is weaker evidence than versioned saves.
3. Describe two checks you would make on an exported product before calling it finished.
4. List four separate component parts that would make strong strand 2a evidence for an app with a home screen, a gallery and a booking form.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
