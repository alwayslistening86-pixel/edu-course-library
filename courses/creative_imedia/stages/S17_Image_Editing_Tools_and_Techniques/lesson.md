# S17_Image_Editing_Tools_and_Techniques - Lesson: Image editing tools and techniques

## Goal
The learner uses canvas, layout, drawing, adjustment, selection, layer, retouching, typography and filter tools effectively, and can show each technique with evidence such as screenshots.

## Syllabus items taught here
- R094-3.1 - Image editing tools and techniques: know how canvas, layout, drawing, adjustment, selection, layer, retouching, type and filter tools are used

## How to teach this
Give the learner a plain photograph and a practice logo and say: 'Show me you can change the size, fix the colour, cut out an object, add text and export it.' Let them explore the software of their school (Photoshop, GIMP, Photopea, Pixlr, Affinity Photo, Krita or similar); OCR does not tell students which software to use. Microsoft Office-based tools are allowed but constrain achievement because many required tools are unavailable.

#### R094-3.1 Image editing tools and techniques
Nine groups of tools are named. Image/canvas size: set or expand the canvas and resize an image. Layout tools: rulers, guides and grids to place assets. Drawing tools: shapes, colour fill, gradients, brush, pencil. Adjustments: brightness and contrast, levels, colour balance, hue and saturation. Selections: based on shape (marquee), colour (magic wand) or edge contrast, used to isolate or edit parts. Layers and layer styles: structure the graphic, create, merge, rename, change opacity; layer styles add drop shadows, effects and textures. Retouching: cloning, healing, blur, the colour picker, swatches, pencil and brush to remove unwanted elements. Typography: text, font styles, sizes and effects to add information. Filters and effects: stylise, monochrome, colour toning, vignette, sharpen to enhance visual appeal. Masks and customising tools are not included. The assessment cares how effectively each technique is used, not the polish of the final picture alone, so learners must be able to evidence the technique: annotated screenshots of the tool in use and the result. Screenshots showing the software and settings are not a step-by-step guide to copy, but proof of what the learner did. Naming and organising layers clearly also helps a moderator follow the work.

## Explicitly not here
Sourcing, creating and preparing assets (S18) and saving and exporting (S19).
