# S25_R097_Repurposing_Audio_Moving_Image_and_Interactive_Assets - Practice: Repurposing audio, moving image and interactive assets, and organising the product folder

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Describe two specific techniques for repurposing an audio clip and why each might be needed.
2. Describe how you would optimise a video clip differently for a kiosk versus a website.
3. Describe the three visual states a well-built button should have and why.
4. Sketch a product folder structure with a naming convention for a five-screen app.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
