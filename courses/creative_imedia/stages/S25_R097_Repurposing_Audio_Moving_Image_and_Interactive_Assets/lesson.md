# S25_R097_Repurposing_Audio_Moving_Image_and_Interactive_Assets - Lesson: Repurposing audio, moving image and interactive assets, and organising the product folder

## Goal
The learner repurposes audio and moving image assets, creates interactive assets and structures a well-named product folder.

## Syllabus items taught here
- R097-2.1c - Audio assets: types and repurposing: cut, split, trim, extend, adjust volume and optimise sound effects, narration and music
- R097-2.1d - Moving image assets: types and repurposing: import, sequence, trim, adjust and optimise video and animation assets
- R097-2.1e - Interactive assets: buttons, banners, navigation bars, maps, diagrams and forms: create interactive elements with suitable software tools
- R097-2.2a - Product folder management and file naming: structure root, images, media and styles folders and use naming conventions

## How to teach this
Play a short raw sound clip, then a version trimmed and level-adjusted for a product. 'What changed, and why does it matter for the finished product?' Use this to show that repurposing is a skill applied consistently across every asset type, not just images.

#### R097-2.1c Audio assets: types and repurposing
Audio assets (sound effects, narration, music) are repurposed by cutting and splitting (removing unwanted sections), trimming, extending (looping or stretching to fit a duration), adjusting volume/level (so nothing is too quiet or clips) and general optimisation (removing background noise, normalising level across clips). As with images, repurposing must be visible and purposeful: a narration clip trimmed to remove a mistake and normalised to match other narration in the product, not audio dropped in unedited. Learners should be able to name the specific technique used and why. Activity: describe how you would edit a raw 90-second narration clip down to a clean 45-second version for one screen of the booking product.

#### R097-2.1d Moving image assets: types and repurposing
Moving image assets (video and animation) are repurposed by importing source footage, sequencing clips in order, trimming unwanted sections, adjusting (colour, speed, transitions) and optimising for the target product (correct resolution, frame rate and file size so it plays smoothly on the intended device). A short demo clip for a kiosk, for example, needs different optimisation from the same footage used on a website. Learners should connect their repurposing choices back to the device and format decided in planning (S20, S22). Activity: describe how a 3-minute raw video tour of the leisure centre would be trimmed and optimised for a 30-second homepage clip.

#### R097-2.1e Interactive assets: buttons, banners, navigation bars, maps, diagrams and forms
Interactive assets are built (not just sourced) using suitable software tools: buttons and navigation bars with clear states (normal, hover, clicked), banners that link somewhere purposeful, interactive maps or diagrams (for example a clickable site map), and forms with appropriate fields and validation. These should match the asset table and navigation diagram from planning exactly, since interactive assets are what make the product interactive rather than a static page. Activity: describe how you would build a "book now" button with three visual states for the leisure-centre product.

#### R097-2.2a Product folder management and file naming
A well-organised product uses a clear folder structure (for example separate root, images, media and styles folders) and a consistent file-naming convention (short, descriptive, no spaces, consistent case) so that assets can be found, replaced and linked reliably. Poor folder management is a common cause of broken links and lost work when a product grows beyond a handful of files, and OCR expects this organisation to be visible as evidence, not just functional. Activity: sketch a folder structure for the booking product with at least four folders and explain the naming convention chosen.
