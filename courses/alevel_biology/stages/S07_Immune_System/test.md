# S07_Immune_System - Test: Cell recognition and the immune system

## How to run this
A real checkpoint in the style of AQA's papers: structured questions with marks shown (and some multiple choice). Give the whole test at once, with no hints; the learner shows working and may use a calculator. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Describe the humoral response to a bacterial infection. [5 marks]
2. Explain why the secondary response to an antigen is faster than the primary response. [2 marks]
3. Explain how HIV causes the symptoms of AIDS. [3 marks]
4. Describe how an indirect ELISA test detects antibodies to a pathogen in a blood sample. [4 marks]
5. Explain why antibiotics can't be used to treat viral infections. [2 marks]

## Answer key (for the tutor only)
1. [5] B1 a B cell with a complementary antibody on its surface binds the antigen; B1 takes it in and presents it; B1 helper T cells activate the B cell; B1 clonal selection: B cell divides by mitosis; B1 into plasma cells that secrete antibodies and memory cells.
2. [2] B1 memory cells remain after the first exposure; B1 they divide rapidly into plasma cells (and T cells), producing antibodies quickly and in larger amounts.
3. [3] B1 HIV infects helper T cells; B1 replication destroys them, so their number falls; B1 the immune response can't be activated, leading to opportunistic infections.
4. [4] B1 antigen bound to the well; B1 add the sample: specific antibodies bind; wash; B1 add a second antibody with an enzyme attached, which binds the first antibody; wash to remove unbound antibody; B1 add substrate: colour change shows the antibody was present.
5. [2] B1 antibiotics target bacterial structures/processes (e.g. murein cell walls, 70S ribosomes); B1 viruses lack these and replicate inside host cells.
