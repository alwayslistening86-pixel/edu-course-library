# S11_Genes_and_Protein_Synthesis - Test: DNA, genes, chromosomes and protein synthesis

## How to run this
A real checkpoint in the style of AQA's papers: structured questions with marks shown (and some multiple choice). Give the whole test at once, with no hints; the learner shows working and may use a calculator. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Describe the process of transcription in a eukaryotic cell. [5 marks]
2. Explain what is meant by the genetic code being degenerate and universal. [2 marks]
3. Describe the role of tRNA in translation. [3 marks]
4. Compare the DNA in a eukaryotic nucleus with the DNA in a prokaryotic cell. [3 marks]
5. A mature mRNA molecule has 1,503 bases from the first base of the start codon to the last base of the stop codon. How many amino acids are in the polypeptide it codes for? [1 mark]
6. Which features are found in mRNA but not DNA? Choose every correct option.
   A. uracil
   B. ribose
   C. deoxyribose
   D. hydrogen bonds between two strands

## Answer key (for the tutor only)
1. [5] B1 hydrogen bonds between DNA bases break, exposing the template strand; B1 free RNA nucleotides pair with complementary bases (U with A); B1 RNA polymerase joins nucleotides (phosphodiester bonds); B1 forming pre-mRNA; B1 splicing removes introns to form mRNA, which leaves the nucleus.
2. [2] B1 degenerate: more than one triplet codes for the same amino acid; B1 universal: the same triplets code for the same amino acids in (almost) all organisms.
3. [3] B1 each tRNA carries a specific amino acid; B1 its anticodon pairs with the complementary codon on mRNA; B1 bringing amino acids into the correct order so peptide bonds can form.
4. [3] B1 eukaryotic: linear, prokaryotic: circular; B1 eukaryotic DNA associated with histones, prokaryotic not; B1 eukaryotic DNA has introns/non-coding repeats (prokaryotic genes mostly lack introns).
5. [1] B1 500 (501 codons, the last being a stop codon).
6. Correct: A, B (exactly these options, no others)
