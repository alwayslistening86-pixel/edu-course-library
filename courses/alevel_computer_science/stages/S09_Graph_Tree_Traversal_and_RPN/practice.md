# S09_Graph_Tree_Traversal_and_RPN - Practice: Graph and tree traversal, and Reverse Polish notation

## Goal
Low-stakes practice: the learner predicts or attempts each item first, then checks it (by running code, or against the model answer). Mistakes are expected and corrected here, before any grading.

## Practice items
1. For the graph with edges A-B, A-C, B-D, C-D (undirected, neighbours visited alphabetically), state the order nodes are visited by breadth-first search starting at A. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 visits A first, then its neighbours B and C; B1 full order: A, B, C, D.

## How to run it
One item at a time. For code-output/trace items the learner commits to a prediction before running or checking anything. Offer a worked explanation only after a genuine attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
