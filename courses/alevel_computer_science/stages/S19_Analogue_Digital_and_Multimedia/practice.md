# S19_Analogue_Digital_and_Multimedia - Practice: Analogue/digital data, images, sound, compression and encryption

## Goal
Low-stakes practice: the learner predicts or attempts each item first, then checks it (by running code, or against the model answer). Mistakes are expected and corrected here, before any grading.

## Practice items
1. Apply run-length encoding to the string "WWWWBBBWWBB". [2 marks]
2. Explain one advantage vector graphics have over bitmapped graphics when an image needs to be scaled up significantly. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [2] B1 correct runs identified: W(4), B(3), W(2), B(2); B1 correct RLE output: 4W3B2W2B.
2. [2] B1 a vector image is recalculated/redrawn from its mathematical description at the new size, so it stays sharp at any scale; B1 a bitmap image only has a fixed grid of pixels, so scaling it up enlarges those same pixels, causing visible pixelation/blurring.

## How to run it
One item at a time. For code-output/trace items the learner commits to a prediction before running or checking anything. Offer a worked explanation only after a genuine attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
