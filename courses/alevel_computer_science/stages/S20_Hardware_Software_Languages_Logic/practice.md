# S20_Hardware_Software_Languages_Logic - Practice: Hardware/software/the OS, language classification and translators, logic gates and Boolean algebra

## Goal
Low-stakes practice: the learner predicts or attempts each item first, then checks it (by running code, or against the model answer). Mistakes are expected and corrected here, before any grading.

## Practice items
1. Classify each as system software or application software: (a) an operating system; (b) a spreadsheet program; (c) a device driver. [3 marks]
2. Draw the truth table for the AND gate with inputs A and B. [2 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [3] B1 (a) system software; B1 (b) application software; B1 (c) system software.
2. [2] B1 correctly lists all four input combinations (0,0)(0,1)(1,0)(1,1); B1 correct outputs 0,0,0,1 respectively.

## How to run it
One item at a time. For code-output/trace items the learner commits to a prediction before running or checking anything. Offer a worked explanation only after a genuine attempt.

## When to move to test
When the learner gets a new item of each type right without prompting.
