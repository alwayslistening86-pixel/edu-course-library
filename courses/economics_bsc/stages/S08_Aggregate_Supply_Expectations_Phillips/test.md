## Test items
1. Explain why long-run aggregate supply is drawn as a vertical line, and what determines its position. [3 marks]
2. Using pi = pi^e - 0.6(u - u*), with u* = 4.5% and pi^e = 2.5%: calculate inflation if unemployment is 3.5%, and again if unemployment is 5.5%. [4 marks]
3. Explain the time-inconsistency problem facing a central bank without a credible commitment mechanism. [4 marks]
4. Which are implications of the expectations-augmented Phillips curve? Choose every correct option.
   A. The long-run Phillips curve is vertical at the NAIRU
   B. Only unanticipated inflation is linked to unemployment below the natural rate
   C. Unemployment can be kept permanently below the natural rate by tolerating higher inflation
   D. A credible disinflation reduces the output cost of lowering inflation

## Answer key (for the tutor only)
1. [3] B1 in the long run wages and prices fully adjust to any price-level change, so there is no lasting effect on real output; B1 output is determined by real factors: the capital stock, labour force and technology/productivity, not the price level; B1 so LRAS is vertical at the economy's potential (natural) level of output, shifting only when these real factors change.
2. [4] M1 at u=3.5: pi = 2.5 - 0.6x(4.5-3.5) = 1.9%; M1 at u=5.5: pi = 2.5-0.6x(4.5-5.5) = 3.1%; A1 both correct; B1 unemployment below NAIRU is associated with inflation above expected, and above NAIRU with inflation below expected -- the short-run trade-off.
3. [4] B1 once private agents have set wages/prices based on an inflation promise, the bank has an incentive to renege and create surprise inflation to temporarily boost output/lower unemployment; B1 but rational agents anticipate this incentive and build higher expected inflation into contracts in the first place; B1 the result is higher actual inflation with no lasting output gain (worse of both outcomes); B1 independent central banks and explicit inflation targets are used as commitment devices to restore credibility.
4. Correct: A, B, D (exactly these options, no others)
