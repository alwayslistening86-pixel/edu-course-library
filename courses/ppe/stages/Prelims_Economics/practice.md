# Prelims_Economics - Practice: Introductory Economics - Microeconomics, Macroeconomics, Quantitative Methods

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Derive the profit-maximising output for a monopolist facing a linear demand curve and constant marginal cost, and compare it with the competitive outcome.
2. Explain, using monopsony, how a minimum wage above the competitive wage could raise employment rather than lower it.
3. Using the national accounting identity, explain what happens to output if investment falls and nothing else adjusts.
4. Set up and solve a simple utility-maximisation problem subject to a budget constraint using a Lagrangian.
5. Explain the difference between correlation and a credible causal estimate, using the minimum-wage employment debate as your example.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
