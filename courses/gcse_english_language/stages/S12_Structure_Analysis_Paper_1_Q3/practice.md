# S12_Structure_Analysis_Paper_1_Q3 - Practice: Analysing structure: Paper 1 Question 3 (8 marks)

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Say what each structural choice does: (a) a story opens with a single-line paragraph: 'The letter was already open.' (b) a description moves from a whole city to one lit window. (c) the last paragraph repeats the first sentence.
2. Sketch the tension graph of an extract you know (rise, dip, peak) and label where the writer changed focus.
3. Explain the difference between a language comment and a structure comment on the same short passage.
4. Write four sentences for 'How has the writer used structure to build tension as the passage develops?' (the 2026 named-effect format) using an original extract given by your tutor.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
