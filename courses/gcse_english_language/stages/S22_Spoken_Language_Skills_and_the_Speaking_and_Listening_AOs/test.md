# S22_Spoken_Language_Skills_and_the_Speaking_and_Listening_AOs - Test: Presenting, responding and using spoken Standard English; the speaking and listening assessment objectives

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Deliver (or write out, if speaking aloud is not possible in this format) a 2-minute talk on 'Why my school/college should change one rule', structured with an opener, two developed points and a summing-up, in spoken Standard English throughout. Then answer this follow-up question directly: 'What would you say to someone who disagreed with your second point?'

## Grading
Apply `rubric.json`'s `stage_rubrics.S22_Spoken_Language_Skills_and_the_Speaking_and_Listening_AOs` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to S23_Spoken_Language_Endorsement_Criteria_and_Reporting.
