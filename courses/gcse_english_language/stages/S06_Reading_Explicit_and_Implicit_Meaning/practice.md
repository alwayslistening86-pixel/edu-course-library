# S06_Reading_Explicit_and_Implicit_Meaning - Practice: Reading closely: explicit and implicit information, themes and inference

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. For 'Aunt Meg wiped the same clean table for the third time as the clock struck eight', write one explicit fact and two inferences, each with a because-clause.
2. Give a theme (in a phrase) for this line: 'Everyone else had already unpacked; I stood in the hall with my suitcase still zipped.'
3. Choose the best three-word quotation to prove 'the house is neglected' from: 'The gate hung by one hinge. Weeds had colonised the steps. A curtain stirred at an upstairs window.' Explain your choice.
4. Rewrite this weak point to include an embedded quotation and comment: 'The writer says the road was long.'

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
