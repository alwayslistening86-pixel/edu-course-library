# S11_Language_Analysis_Paper_2_Q3_and_Persuasive_Devices - Practice: Language on Paper 2: Question 3 (12 marks) and rhetorical devices

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Identify the device: (a) 'Do we really want to leave them behind?' (b) 'The rules, which nobody read, changed daily.' (c) 'Fast to buy, slow to fix.' (d) 'We shall not be silent; we shall not be moved; we shall not go quietly.'
2. Write an original persuasive sentence using a triple and explain why three works.
3. Rewrite this description so it is neutral, then explain what emotive words were lost: 'The greedy developers ripped out the beloved old oak.'
4. Write a 12-mark style answer (four points) about how a writer uses language to convey anger in an original 6-line extract you or your tutor selects.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
