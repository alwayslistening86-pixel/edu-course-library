# S15_Comparison_Paper_2_Q4 - Practice: Comparing perspectives: Paper 2 Question 4 (16 marks)

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write a comparative topic sentence for: Source A calls the sea 'cruel'; Source B calls it 'a friend'.
2. Identify three methods a writer might use to show anger versus admiration.
3. Turn two separate sentences (one on each source) into one comparative sentence using 'whereas'.
4. Read two short original sources on the same subject (for example a street market in 1880 and today) and write one comparison paragraph.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
