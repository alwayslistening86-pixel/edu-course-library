# S02_A1_Grammar_Numbers_Pronouns - Practice: Verbs, pronouns, numbers and simple negative sentences

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Conjugate a lucra, a vedea, a merge and a dormi fully in the present tense.
2. Write five questions about a classmate using cine, ce, unde, când, and câți, then answer them.
3. Say the time for 7:00, 7:15, 7:30 and 7:45, and name today's day and month in Romanian.
4. Turn these into negative sentences: "Sunt profesor.", "Am o mașină.", "Lucrez la Cluj."
5. Complete with the correct demonstrative/possessive: "___ carte (this) este ___ (my)."

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
