# S16_B2_Grammar_Subjunctive_Passive - Practice: The full subjunctive system, conditional perfect and the passive voice

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write three sentences using the past subjunctive expressing doubt or regret about something in the past.
2. Write three hypothetical sentences: two about the present/future, one about the past, using the correct conditional forms.
3. Turn five active sentences into the passive voice, with correct participle agreement.
4. Write three sentences using the gerund to express simultaneous action.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
