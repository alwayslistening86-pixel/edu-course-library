# S07_A2_Grammar_Adjectives_Prepositions - Practice: Describing, comparing and locating things

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Conjugate a face, a putea, a vrea, a ști and a veni fully in the present tense and use each in one sentence.
2. Describe a person and a place using at least six adjectives with correct gender/number agreement.
3. Write three comparative and two superlative sentences comparing people, places or things you know.
4. Describe where five objects are in a room using different prepositions of place.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
