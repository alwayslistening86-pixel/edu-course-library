# S23_C2_Grammar_Mastery_Vocab - Practice: Rare constructions, literary register, full case precision and register range

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Identify and gloss three rare/archaic constructions in a given short paraphrased literary passage.
2. Write an original short descriptive paragraph imitating classic literary register (inversion, adjective chains).
3. Write five sentences combining dative and accusative clitics correctly, including one reflexive-dative fusion.
4. Use four proverbs/idioms from the C2 set appropriately in original sentences.
5. Identify the register (formal/neutral/legal/slang/academic) of ten given words or phrases and explain the cue that identifies each.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
