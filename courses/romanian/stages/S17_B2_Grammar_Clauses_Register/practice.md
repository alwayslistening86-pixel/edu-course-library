# S17_B2_Grammar_Clauses_Register - Practice: Complex clauses, the vocative case and formal register

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Write three concessive sentences and three purpose sentences on a topic of your choice.
2. Address five different people (a friend, a teacher, a doctor, a generic "sir", a child) using correct vocative forms.
3. Report five statements originally made in different tenses, applying full tense-shift rules.
4. Write five sentences using formal genitive-dative noun case endings instead of al/a/ai/ale paraphrase.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
