# S17_B2_Grammar_Clauses_Register - Test: Complex clauses, the vocative case and formal register

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Write a formal letter (8-10 sentences) to a professor or official: address them correctly using the vocative, explain a request using a purpose clause, acknowledge an obstacle with a concessive clause, report something you were told previously (full tense-shift), and use at least one formal genitive-dative case ending.

## Grading
Apply `rubric.json`'s `stage_rubrics.S17_B2_Grammar_Clauses_Register` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass and let the learner know they can move to S18_B2_Vocab_Abstract_Topics.
