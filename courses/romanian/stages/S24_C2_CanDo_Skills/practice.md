# S24_C2_CanDo_Skills - Practice: C2 can-do check: near-native mastery across every skill

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Listen to (or read aloud) fast, natural speech with regional/colloquial features and answer nuance-level questions.
2. Read a dense abstract text and a literary-register text fluently, answering comprehension and interpretive questions.
3. Take part in a fast-paced discussion with abrupt topic shifts and idiomatic language, responding precisely.
4. Give a 5-6 minute presentation on a complex topic, adapted explicitly to a stated audience.
5. Write a 350-400 word report or article in a specified register.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
