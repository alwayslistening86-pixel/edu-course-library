# S24_C2_CanDo_Skills - Test: C2 can-do check: near-native mastery across every skill

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Combined mini-assessment: (1) listen to/read fast, natural speech with colloquial/regional features and answer nuance questions; (2) read a dense abstract or literary text fluently and answer interpretive questions; (3) take part in a fast-paced, idiom-rich discussion; (4) give an audience-adapted 5-6 minute presentation on a complex topic; (5) write a 350-400 word piece in a specified register.

## Grading
Apply `rubric.json`'s `stage_rubrics.S24_C2_CanDo_Skills` criteria exactly. Record `passed` or `not_passed`, with a short honest note on strengths/weaknesses, into this course's micro-profile.

## If not passed
Name the specific weak or missing step, offer to revisit practice, then re-test with a new question of the same type.

## On pass
Record the pass. This was the last stage: the cumulative exam is now unlocked once every stage test is passed.
