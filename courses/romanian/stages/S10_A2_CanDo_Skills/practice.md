# S10_A2_CanDo_Skills - Practice: A2 can-do check: everyday exchanges and simple connected description

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Listen to (or read aloud at natural pace) a short shop or travel exchange and extract three specific facts.
2. Read a mock timetable or job advert and answer two factual questions.
3. Role-play a routine transaction (shopping, travel booking or pharmacy visit) unscripted.
4. Give a two-minute spoken description of family, home, education and work/school.
5. Write a short arranging note and a simple thank-you letter.

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
