## Test items
1. Explain how the development of a multi-party system has affected UK government since 2010. [9 marks]
2. [Paper 1, Section B style, using PP2.2] Evaluate the extent to which the Labour Party has abandoned its founding principles. [24 marks]

[24] Mark out of 24 using Edexcel's generic levels for extended political writing: Level 1 (1-5) basic, undeveloped; Level 2 (6-10) some accurate knowledge, limited analysis, mostly descriptive; Level 3 (11-15) accurate knowledge, developed analysis of similarities/differences/tensions, some use of named thinkers, but uneven depth; Level 4 (16-20) accurate, wide-ranging knowledge, sustained analysis using thinkers effectively, evaluation reaching a judgement; Level 5 (21-24) excellent, precise knowledge, sophisticated analysis integrating thinkers throughout, and a fully substantiated, well-weighed judgement.
