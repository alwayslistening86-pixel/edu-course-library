# MI_S02_Budgeting_and_Forecasting - Test: Budgeting and forecasting

## How to run this

## Test items
1. Total cost is £48,000 at 10,000 units and £57,000 at 14,000 units. Use the high-low method to estimate the variable cost per unit and the fixed cost. [3 marks]
2. Budgeted sales are 11,000 units. Desired closing inventory is 1,300 units and opening inventory is 900 units. Calculate the production budget. [2 marks]
3. Which budgeting approach requires every cost to be justified from zero each period, regardless of the prior year's budget? Choose every correct option.
   A. Incremental budgeting
   B. Zero-based budgeting
   C. Top-down budgeting only
   D. Rolling budgeting
4. Inventory holding period is 38 days, receivables collection period is 52 days, and payables payment period is 40 days. Calculate the cash operating cycle and explain what a reduction in the receivables period would do to it. [3 marks]
5. Which is the main purpose of a cash budget, as distinct from a budgeted income statement? Choose every correct option.
   A. To calculate the year's total accounting profit
   B. To identify the timing of cash shortfalls or surpluses so action can be taken in advance
   C. To value closing inventory
   D. To set the selling price

## Answer key (for the tutor only)
1. [3] M1 variable cost/unit = (57,000-48,000)/(14,000-10,000) = £2.25; M1 fixed cost = 57,000 - 2.25 x 14,000; A1 = £25,500.
2. [2] M1 production = 11,000 + 1,300 - 900; A1 = 11,400 units.
3. Correct: B (exactly these options, no others)
4. [3] M1 cash operating cycle = 38 + 52 - 40; A1 = 50 days; B1 reducing the receivables collection period would shorten the cash operating cycle, releasing cash sooner and reducing the working capital tied up.
5. Correct: B (exactly these options, no others)
