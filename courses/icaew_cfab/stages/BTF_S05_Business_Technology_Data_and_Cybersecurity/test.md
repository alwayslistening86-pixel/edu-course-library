   D. An annual financial statement audit

4. Under UK GDPR, personal data must be: Choose every correct option.
   A. kept indefinitely for safety

   D. exempt from any security requirement if stored digitally
5. Phishing is best described as: Choose every correct option.
   A. a legitimate IT security audit technique
   B. a deceptive message intended to obtain credentials or install malware
   C. a type of encryption
   D. a UK data protection law
