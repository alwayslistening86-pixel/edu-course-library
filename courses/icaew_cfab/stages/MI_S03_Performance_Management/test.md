# MI_S03_Performance_Management - Test: Performance management: variance analysis

## How to run this

## Test items
1. Standard material cost is 3 kg @ £8.00/kg per unit. 1,500 units are made using 4,700 kg costing £36,660. Calculate the material price and usage variances, stating whether each is favourable or adverse. [6 marks]
2. Standard profit per unit is £12. Budgeted sales are 5,000 units; actual sales are 4,700 units. Calculate the sales volume variance. [3 marks]
3. A favourable material price variance most likely arose because: Choose every correct option.
   A. more material was used per unit than standard
   B. the actual price paid per kg was lower than the standard price
   C. output was higher than budgeted
   D. labour worked less efficiently than standard
4. An adverse labour efficiency variance means: Choose every correct option.
   A. actual hours worked exceeded the standard hours allowed for actual output
   B. the actual labour rate was lower than standard
   C. output was below budget
   D. actual hours were exactly as standard
5. Standard cost of output is £60,000 (based on standard cost per unit x actual output) and actual cost incurred is £63,500. State the total cost variance and whether it is favourable or adverse. [2 marks]

## Answer key (for the tutor only)
1. [6] M1 actual price = 36,660/4,700 = £7.80/kg; M1 price variance = (8.00 - 7.80) x 4,700 = £940; A1 favourable; M1 standard quantity for 1,500 units = 4,500 kg; M1 usage variance = (4,500-4,700) x 8.00 = £-1,600; A1 adverse (more material used than the standard allows).
2. [3] M1 volume difference = 4,700 - 5,000 = -300 units; M1 variance = -300 x £12; A1 = £-3,600 adverse (fewer units sold than budgeted, valued at standard profit per unit).
3. Correct: B (exactly these options, no others)
4. Correct: A (exactly these options, no others)
5. [2] M1 total variance = 60,000 - 63,500 = £-3,500; A1 = £3,500 adverse (actual cost exceeded the standard cost of the output achieved).
