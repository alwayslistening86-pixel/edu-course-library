# MI_S03_Performance_Management - Lesson: Performance management: variance analysis

## Goal
The learner calculates variances between actual and budgeted/standard performance, splitting a cost variance into its price and volume effects.

## Syllabus items taught here
- MI.3a - Standard costing and variance analysis - materials
- MI.3b - Material price and usage variances (worked)
- MI.3c - Labour and sales variances

## How to teach this
Ask: if a factory's material cost comes in £8,000 over budget, is that because it paid more per kilogram, used more kilograms than it should have, or both? Have the learner predict the result of every example before running it, and run code for real whenever they can.

#### MI.3a Standard costing and variance analysis - materials
**Standard costing and variance analysis**: a **standard cost** is a predetermined estimate of what a unit should cost, based on standard quantities and standard prices/rates. Comparing actual results with the standard cost of actual output (the 'flexed' budget) produces **variances**. **Material variances**: **price variance** = (standard price - actual price) x actual quantity, **usage variance** = (standard quantity for actual output - actual quantity used) x standard price. A positive result is **favourable** (better than standard); negative is **adverse**.

#### MI.3b Material price and usage variances (worked)
*Worked example*: standard cost is 4 kg @ £5.00/kg per unit. 1,000 units are made using 4,300 kg costing £22,360 in total (average £5.20/kg). Price variance = (5.00 - 5.20) x 4,300 = £-860 (adverse, since the actual price per kg exceeded standard). Usage variance = (4,000 - 4,300) x 5.00 = £-1,500 (adverse, since more material was used than the standard 4,000 kg for 1,000 units). Total material variance = £-2,360, which equals standard cost of output (4,000 x £5.00 = £20,000) minus actual cost (£22,360) = £-2,360.

#### MI.3c Labour and sales variances
The same **price/rate and usage/efficiency** split applies to labour (rate variance = (standard rate - actual rate) x actual hours; efficiency variance = (standard hours for actual output - actual hours) x standard rate) and to sales (**sales price variance** = (actual price - standard price) x actual quantity sold; **sales volume variance** = (actual quantity - budgeted quantity) x standard profit per unit) - separating a 'how much per unit' effect from a 'how many units' effect is the recurring idea behind every variance in this pair structure.
