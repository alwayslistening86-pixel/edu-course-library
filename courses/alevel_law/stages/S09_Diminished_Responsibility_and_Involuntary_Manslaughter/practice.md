# S09_Diminished_Responsibility_and_Involuntary_Manslaughter - Practice: Voluntary manslaughter -- diminished responsibility; involuntary manslaughter

## Goal
Low-stakes practice: the learner attempts each question with a full answer before seeing the model. Mistakes are expected and corrected here, before any grading.

## Practice items
1. State the four elements the defendant must prove for diminished responsibility under s2 Homicide Act 1957 (as amended). [4 marks]

## Answers (for the tutor; reveal only after a genuine attempt)
1. [4] B1 an abnormality of mental functioning; B1 arising from a recognised medical condition; B1 which substantially impaired understanding conduct/forming rational judgment/exercising self-control (any one); B1 which provides an explanation for the killing.

## How to run it
One question at a time. Let the learner finish an attempt before offering a hint; then walk through the model answer and have them redo any step they missed.

## When to move to test
When the learner gets a new item of each type right without prompting.
