# S02_Complex_Numbers_Basics - Test: Complex numbers: forms, notation and arithmetic

## How to run this
A real checkpoint in the style of OCR's Further Mathematics papers: structured questions with marks shown. Give the whole test at once, with no hints; the learner shows full working and may use a calculator. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Find the square roots of -7 - 24i. [5 marks]
2. Solve z^2 + 6z + 34 = 0. [2 marks]
3. Express z = -2 + 2i in modulus-argument form, and hence write down z^* in modulus-argument form. [4 marks]
4. Find the real numbers x and y such that (x + iy)(2 - i) = 8 + i. [3 marks]
5. Given z = 1 + 2i, find in the form a + bi: (a) z^2 - 2z*, (b) 1/z. [4 marks]

## Answer key (for the tutor only)
1. [5] M1 (a + ib)^2: a^2 - b^2 = -7, 2ab = -24; M1 eliminates b; A1 a^4 + 7a^2 - 144 = 0, a^2 = 9; A1 a = ±3, b = ∓4; A1 ±(3 - 4i).
2. [2] M1 formula with negative discriminant; A1 -3 ± 5i.
3. [4] B1 |z| = 2root2; M1 argument in the second quadrant; A1 3π/4; B1 z* = 2root2(cos(-3π/4) + i sin(-3π/4)).
4. [3] M1 expands and equates parts: 2x + y = 8, 2y - x = 1; A1 x = 3; A1 y = 2.
5. [4] M1 z^2 = -3 + 4i; A1 (a) -5 + 8i; M1 conjugate over |z|^2; A1 (b) 1/5 - 2/5i.
