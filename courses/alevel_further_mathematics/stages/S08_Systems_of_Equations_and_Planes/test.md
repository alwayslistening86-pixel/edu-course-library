## Test items
1. The system x + 2y + z = 4, 2x + 3y + 3z = 7, x + y + 2z = k has no unique solution. (a) Show this by finding a determinant. (b) Find the value of k for which the system is consistent and describe the geometry. (c) Describe the geometry for other values of k. [7 marks]
2. Explain what it means for two of three planes to have parallel normal vectors, and state the possible arrangements. [2 marks]

## Answer key (for the tutor only)
1. [7] M1 det = 0; A1 so no unique solution; M1 eq2 - eq1 gives x + y + 2z = 3; A1 consistent when k = 3; B1 sheaf of planes meeting in a common line; B1 for k ≠ 3 inconsistent; B1 no two normals parallel, so a prism.
2. [2] B1 those two planes are parallel (or identical); B1 so the system has no solution unless they coincide (with the third meeting them in a line).
