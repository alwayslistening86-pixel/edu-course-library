# S26_Probability_Basics - Practice: Probability basics, relative frequency and counting

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. A bag holds 5 red, 3 blue and 2 green counters. Find P(blue), P(not red) and the expected number of blue counters in 60 draws with replacement.
2. A spinner is spun 200 times and lands on 'A' 74 times. Estimate P(A). Explain why more spins give a better estimate.
3. Draw a grid for two spinners numbered 1 to 4 and find the probability that the product is greater than 8.
4. A PIN has four digits from 0 to 9. How many PINs are possible if repeats are allowed? If no repeats? Higher: how many 3-letter codes can be made from the letters A to F if the code must start with a vowel and letters cannot repeat?

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
