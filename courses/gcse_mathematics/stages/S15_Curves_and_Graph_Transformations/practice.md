# S15_Curves_and_Graph_Transformations - Practice: Curves, trigonometric and exponential graphs, circles and graph transformations

## Goal
Learner starts applying the method to short, low-stakes questions -- mistakes expected and corrected before any grading happens.

## Practice scenarios (use or adapt as needed)
1. Sketch y = x^2 - 6x + 8, marking the roots, the y-intercept and the turning point.
2. Match each equation to a sketch: y = x^3, y = 3/x, y = 2^x, y = -x^2 + 4. Explain your choices using key features.
3. Higher: sketch y = sin x for 0 to 360 degrees and use it to solve sin x = -0.5. Write the equation of the circle with centre the origin through (5, 12).
4. Higher: the graph of y = f(x) has a turning point (3, -2). State the turning points of y = f(x) + 4, y = f(x - 5) and y = -f(x).

## How to run it
Present one question at a time. Let the learner attempt it fully, showing working or reasoning, before correcting. Offer a worked example only after a genuine attempt.

## When to move to test
Once the learner can handle a new, similar question correctly without step-by-step prompting.
