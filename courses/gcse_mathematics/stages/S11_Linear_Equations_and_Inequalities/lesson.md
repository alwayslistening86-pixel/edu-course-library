# S11_Linear_Equations_and_Inequalities - Lesson: Linear equations and inequalities

## Goal
The learner solves linear equations, builds equations from contexts, solves linear (and, at Higher, quadratic) inequalities, and represents inequalities on number lines and graphs.

## Syllabus items taught here
- 6.03a - Solve linear equations; set up from context: solve linear equations and build them from words
- 6.04a - Linear and quadratic inequalities: solve inequalities and show them on a number line
- 6.04b - Inequalities in two variables, graphically (Higher): shade regions defined by inequalities

## How to teach this
Give: 'I think of a number, double it and add 5. The answer is 17.' Ask the learner to solve it and to explain each step before showing the algebraic version.

#### 6.03a Solving linear equations and setting them up
Do the same to both sides. 3x - 7 = 11 gives 3x = 18 and x = 6. Unknowns on both sides: 2(x + 4) = 3x - 5 gives 2x + 8 = 3x - 5, so 13 = x. With fractions, multiply through: (x + 1)/3 = 4 gives x + 1 = 12, x = 11. To set up from a context, name the unknown first: 'the perimeter of a triangle with sides x, x + 3 and 2x - 1 is 30' gives x + x + 3 + 2x - 1 = 30, 4x + 2 = 30, x = 7. Always check the answer in the original equation.

#### 6.04a Solving linear and quadratic inequalities
Solve as an equation, but reverse the inequality sign when multiplying or dividing by a negative: -2x >= 6 gives x <= -3. 3x - 5 < 10 gives x < 5. On a number line, an open circle means not included (< or >), a filled circle means included (<= or >=). List integer solutions where asked: -2 <= x < 3 gives -2, -1, 0, 1, 2. Higher: quadratic inequalities. Solve x^2 - 5x + 6 < 0: the roots are 2 and 3 and the curve is below the axis between them, so 2 < x < 3. For x^2 > 9 the solution is x < -3 or x > 3. Sketch the graph each time.

#### 6.04b Inequalities in two variables graphically
Higher only. Draw each boundary line (dashed for < or >, solid for <= or >=), then test a point such as (0, 0) to decide which side satisfies the inequality. For y > 2x - 1, x + y <= 5 and x >= 0, the solution region is where all three are true. Follow the question's instructions on whether to shade the wanted region or the unwanted region. Read off integer coordinates in the region if asked.
