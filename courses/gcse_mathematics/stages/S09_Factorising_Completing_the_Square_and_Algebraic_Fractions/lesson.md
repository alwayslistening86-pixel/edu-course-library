# S09_Factorising_Completing_the_Square_and_Algebraic_Fractions - Lesson: Factorising, completing the square and algebraic fractions

## Goal
The learner factorises expressions and quadratics, completes the square, and simplifies and combines algebraic fractions.

## Syllabus items taught here
- 6.01e - Common factors; factorise quadratics (Higher): factorise expressions fully
- 6.01f - Complete the square (Higher): write a quadratic in completed-square form
- 6.01g - Algebraic fractions (Higher): simplify and combine algebraic fractions

## How to teach this
Ask: 'Which two numbers multiply to make 12 and add to make 7?' Turn it into an algebra puzzle to introduce factorising a quadratic.

#### 6.01e Factorising, including quadratics
Take out the highest common factor: 6x^2 + 9x = 3x(2x + 3). Check by expanding. For x^2 + bx + c find two numbers that multiply to c and add to b: x^2 + 5x + 6 = (x + 2)(x + 3); x^2 - x - 12 = (x - 4)(x + 3). Higher: when the x^2 coefficient is not 1, split the middle term: 2x^2 + 7x + 3 = 2x^2 + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3). Difference of two squares: x^2 - 49 = (x + 7)(x - 7) and 4x^2 - 25 = (2x + 5)(2x - 5).

#### 6.01f Completing the square
Higher only. Write x^2 + bx + c as (x + b/2)^2 - (b/2)^2 + c. For x^2 + 6x + 2: half of 6 is 3, so (x + 3)^2 - 9 + 2 = (x + 3)^2 - 7. When the coefficient of x^2 is not 1, factor it out first: 2x^2 - 12x + 5 = 2(x^2 - 6x) + 5 = 2[(x - 3)^2 - 9] + 5 = 2(x - 3)^2 - 13. The completed square form shows the turning point (3, -13) and lets you solve the equation without the formula.

#### 6.01g Algebraic fractions
Higher only. Simplify by factorising top and bottom and cancelling common factors, never individual terms: (x^2 - 9)/(x^2 + 5x + 6) = (x + 3)(x - 3)/((x + 2)(x + 3)) = (x - 3)/(x + 2). To add or subtract, use a common denominator: 1/(x + 1) + 2/(x - 3) = ((x - 3) + 2(x + 1))/((x + 1)(x - 3)) = (3x - 1)/((x + 1)(x - 3)). To multiply, multiply tops and bottoms; to divide, multiply by the reciprocal. State any values that make a denominator zero if the question asks.
