# S08_Algebraic_Expressions - Lesson: Algebraic expressions: vocabulary, simplifying, expanding and substituting

## Goal
The learner uses algebraic vocabulary correctly, simplifies expressions by collecting terms and applying index laws, expands brackets (including binomial products), and substitutes values into expressions and formulae.

## Syllabus items taught here
- 6.01a - Vocabulary of expressions, equations, formulae, inequalities; equivalence: tell the algebraic objects apart and use identities
- 6.01b - Simplify by collecting like terms: simplify expressions
- 6.01c - Simplify products and quotients with index laws (Higher): simplify algebraic powers, products and quotients
- 6.01d - Expand brackets; multiply binomials: expand single, double and (Higher) triple brackets
- 6.02b - Substitute values into formulae: evaluate a formula for given values

## How to teach this
Ask: 'Is 3x + 2 the same as 5x?' Have the learner substitute x = 4 into both to see they differ, then use the result to introduce the difference between an expression and an equation.

#### 6.01a Algebraic vocabulary and equivalence
An expression has no equals sign (3x + 2). An equation is true only for particular values (3x + 2 = 11). A formula links quantities (A = l x w). An identity is true for every value and is written with the sign for 'is identical to' (3(x + 2) = 3x + 6 for all x). An inequality uses <, >, <=, >=. A term is a part separated by + or -; the coefficient is the number multiplying a letter. To show two expressions are equivalent, expand or simplify one until it matches the other. Higher: prove simple statements algebraically, for example n, n + 1 and n + 2 add to 3n + 3 = 3(n + 1), so the sum of three consecutive integers is always a multiple of 3.

#### 6.01b Collecting like terms
Only like terms (same letters with the same powers) can be combined. 3x + 2y - x + 5y = 2x + 7y. x^2 and x are different, so 4x^2 + 3x - x^2 + x = 3x^2 + 4x. Terms carry the sign in front of them, so watch subtractions.

#### 6.01c Simplifying products and quotients with index laws
Multiply coefficients and add the powers of matching letters: 3a^2 b x 4ab^3 = 12 a^3 b^4. Divide coefficients and subtract powers: 12x^5 y^2 / 4x^2 y = 3x^3 y. Power of a power multiplies indices and applies to the coefficient: (2x^3)^2 = 4x^6. Higher: negative and fractional indices, such as (9x^4)^(1/2) = 3x^2.

#### 6.01d Expanding brackets
Multiply every term inside by the term outside: 3(2x - 5) = 6x - 15; x(x^2 + 4) = x^3 + 4x. For two brackets, multiply each term in the first by each in the second and then collect: (x + 3)(x - 2) = x^2 - 2x + 3x - 6 = x^2 + x - 6. A squared bracket is two brackets: (x - 4)^2 = x^2 - 8x + 16, not x^2 + 16. Higher: three brackets, e.g. (x + 1)(x + 2)(x + 3) = x^3 + 6x^2 + 11x + 6, expanding two first and then the third.

#### 6.02b Substituting into formulae and expressions
Replace each letter with its value, using brackets for negatives so that (-3)^2 = 9. If x = -3, 2x^2 - 5x = 2(9) - 5(-3) = 18 + 15 = 33. Substitute into a formula such as v = u + at with u = 4, a = 3, t = 5 to get 19. Follow the order of operations and check units in context.
