# S02_Fractions_and_Decimals - Test: Fractions and decimals: equivalence, arithmetic and ordering

## How to run this
Real checkpoint, not more practice. Present the scenario once, let the learner submit a full answer, then grade against this stage's entry in `rubric.json` -- never grade without it.

## Test scenario
Foundation: 'a) Work out 3/4 of 260. b) Work out 1 2/3 + 2 3/5. c) Write 7/16 as a decimal. d) Write these in order, smallest first: 0.7, 2/3, 68%, 5/8.' Higher: 'Show that 0.1636363... (with the 63 recurring) can be written as 9/55. Then work out (2 1/4 - 5/6) / (1 1/3) giving your answer as a mixed number.'
