# S07_Redox - Test: Oxidation states and redox equations

## How to run this
A real checkpoint in the style of AQA's papers: structured questions with marks shown (and some multiple choice). Give the whole test at once, with no hints; the learner shows working and may use a calculator, the Periodic Table and the data sheet. Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Write the half-equation for the reduction of dichromate(VI) ions to chromium(III) ions in acidic solution. [2 marks]
2. Combine the half-equations for Cr2O7^2- → Cr^3+ and Fe^2+ → Fe^3+ into an overall equation. [2 marks]
3. In the reaction 2Fe^3+ + 2I- → 2Fe^2+ + I2, identify the oxidising agent and explain in terms of electrons. [2 marks]
4. Give the oxidation states of sulfur in H2S, S, SO2 and H2SO4. [2 marks]
5. Write a half-equation for the oxidation of hydrogen peroxide to oxygen. [1 mark]

## Answer key (for the tutor only)
1. [2] M1 Cr2O7^2- + 14H+ → 2Cr^3+ + 7H2O (atoms balanced); A1 add 6e- to the left.
2. [2] M1 multiply the iron equation by 6; A1 Cr2O7^2- + 14H+ + 6Fe^2+ → 2Cr^3+ + 7H2O + 6Fe^3+.
3. [2] B1 Fe^3+; B1 it gains electrons from I- (it is reduced).
4. [2] B2 -2, 0, +4, +6 (B1 for three correct).
5. [1] B1 H2O2 → O2 + 2H+ + 2e-.
