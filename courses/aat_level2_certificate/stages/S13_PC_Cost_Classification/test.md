# S13_PC_Cost_Classification - Test: Cost classification, cost centres and the costing system

## How to run this
A real checkpoint in AAT's own style: numeric gap-fill calculations, journal/ledger-entry questions and multiple-choice items, with marks shown. Give the whole test at once, with no hints and a calculator allowed (as in the real assessment). Then mark against the mark schemes below and this stage's entry in `rubric.json`.

## Test items
1. Explain the difference between a direct cost and an indirect cost, giving one example of each for a furniture maker. [3 marks]
2. Explain what a semi-variable cost is, and give an example. [2 marks]
3. Explain the difference between a cost centre and a profit centre. [2 marks]
4. Explain why costing systems use many different classifications of cost, while financial accounting uses only historic cost. [3 marks]
5. Which best describes a stepped cost? Choose every correct option.
   A. fixed within a range of output, then jumping to a new fixed level once a threshold is crossed
   B. changing in exact proportion to output at all times
   C. always zero regardless of output
   D. the same as a variable cost

## Answer key (for the tutor only)
1. [3] B1 a direct cost can be traced to a specific unit/job, e.g. the wood used in a specific table; B1 an indirect cost cannot be traced to one unit and is shared across production, e.g. workshop rent or the supervisor's salary; B1 correct examples given for each.
2. [2] B1 a cost with both a fixed element and a variable element; B1 example, e.g. a phone bill with a fixed line rental plus a per-minute/call charge, or a utility bill with a standing charge plus a usage-based charge.
3. [2] B1 a cost centre has costs collected against it but does not generate its own revenue (e.g. a maintenance department); B1 a profit centre generates its own revenue as well as incurring costs, so it can be judged on profit.
4. [3] B1 costing systems support detailed internal planning, control and decision-making, so need cost classified by element, nature and behaviour, and using both actual and budgeted figures; B1 financial accounting exists to produce the statutory financial statements for external users, which report only what has actually (historically) happened; B1 the two systems serve different purposes within the same organisation.
5. Correct: A (exactly these options, no others)
