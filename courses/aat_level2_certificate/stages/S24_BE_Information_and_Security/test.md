## Test items
1. Explain why timeliness and accuracy might sometimes be in tension when producing financial information, and how a finance team might balance them. [3 marks]
2. Explain the difference between archiving and backing up data, and why a finance function needs both. [3 marks]
3. Explain two elements of good cybersecurity practice in a finance function, and the risk each addresses. [2 marks]
4. Which of these best describes the confidentiality principle as it applies to data security? Choose every correct option.
   A. only sharing information with those authorised to see it
   B. keeping a backup copy of all data
   C. making information available as quickly as possible
   D. presenting information in an understandable format

## Answer key (for the tutor only)
1. [3] B1 producing perfectly accurate information can take longer, while a decision may need information quickly (timeliness); B1 there is often a genuine trade-off between waiting for fuller accuracy and delivering information promptly enough to still be useful; B1 valid balancing approach, e.g. providing a reasonable estimate promptly with clearly stated assumptions, refined later, or setting materiality thresholds for how much accuracy a decision actually needs.
2. [3] B1 archiving is retaining records for as long as legally/organisationally required in a retrievable, secure form (a records-retention practice); B1 backing up is keeping copies of data so it can be recovered if the working copy is lost, corrupted or destroyed (a data-loss-prevention practice); B1 both are needed: archiving meets legal/record-keeping obligations, while backups protect against data loss regardless of retention period.
3. [2] B1 valid element one with risk, e.g. strong/regularly-changed passwords, addressing unauthorised access; B1 valid element two with risk, e.g. staff training on phishing, addressing social-engineering attacks (or firewalls/access controls, addressing unauthorised system access).
4. Correct: A (exactly these options, no others)
