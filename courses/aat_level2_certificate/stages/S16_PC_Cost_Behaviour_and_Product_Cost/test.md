# S16_PC_Cost_Behaviour_and_Product_Cost - Test: Cost behaviour and the cost of a product

## Test items
1. Fixed costs are £24,000; variable cost is £10 per unit. Calculate the total cost and cost per unit at (a) 3,000 units and (b) 6,000 units, and explain why the cost per unit changes. [5 marks]
2. Direct materials are £9,000, direct labour £5,500, direct expenses £500, and factory overheads £3,000. Calculate the prime cost and the manufacturing cost. [3 marks]
3. Manufacturing cost for the period is £18,000. Opening WIP is £1,200 and closing WIP is £1,500. Opening finished goods are £2,000 and closing finished goods are £1,800. Calculate the cost of goods manufactured (COGM) and the cost of goods sold (COGS). [4 marks]
4. Which statement about cost behaviour is correct? Choose every correct option.
   A. fixed cost per unit falls as output rises
   B. variable cost per unit falls as output rises
   C. total fixed cost rises with output
   D. total variable cost stays the same regardless of output

## Answer key (for the tutor only)
1. [5] M1 (a) total = 24,000+(10x3,000)=£54,000, cost/unit = 54,000/3,000=£18.00; A1 (a) both figures correct; M1 (b) total = 24,000+(10x6,000)=£84,000, cost/unit = 84,000/6,000=£14.00; A1 (b) both figures correct; B1 explanation: fixed cost per unit falls as output rises because the same fixed total is spread across more units, while variable cost per unit is unchanged.
2. [3] M1 prime cost = 9,000+5,500+500 = £15,000; A1 manufacturing cost = 15,000+3,000 = £18,000; B1 correct method (prime cost = direct materials+labour+expenses; manufacturing cost = prime cost + factory overheads).
3. [4] M1 COGM = 18,000+1,200-1,500 = £17,700; A1 COGM correct; M1 COGS = 17,700+2,000-1,800 = £17,900; A1 COGS correct.
4. Correct: A (exactly these options, no others)
