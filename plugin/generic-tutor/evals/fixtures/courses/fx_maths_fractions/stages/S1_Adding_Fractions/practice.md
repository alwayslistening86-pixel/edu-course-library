# S1_Adding_Fractions - Practice: Adding fractions with different denominators

## Goal
The learner applies the ideas to simple cases, with mistakes expected and corrected.

## Practice scenarios
1. Work out 1/2 + 1/3. - expect: common denominator 6, 3/6 + 2/6 = 5/6
2. Work out 3/4 + 1/6. - expect: common denominator 12, 9/12 + 2/12 = 11/12
3. Work out 2/5 + 1/10 and simplify. - expect: 4/10 + 1/10 = 5/10 = 1/2

## How to run it
One scenario at a time. Let the learner attempt it fully before correcting. Offer a worked example only after a genuine attempt.
