# Sample: Fractions and percentages - Cumulative Exam

## Unlock condition
Only available once every stage in `stage_ladder` has a passed test.

## Format
A short paper of original questions, marked point by point against the key below.

## 4 ready-made items (write the rest fresh, never reusing stage-test items)
1. Work out 3/5 + 1/4. [3 marks]
2. A jacket costing 90 pounds is reduced by 20%. Work out the sale price. [3 marks]
3. Which statement is correct? Choose every correct option.
   A. 1/2 + 1/4 = 3/4
   B. 1/2 + 1/4 = 2/6
   C. 1/3 + 1/3 = 2/3
   D. 1/5 + 1/5 = 2/10
4. A pay rise takes a wage from 400 pounds to 430 pounds a week. Work out the percentage increase. [3 marks]

## Answer key for the ready-made items (tutor only)
1. [3] M1 common denominator 20 (12/20 + 5/20); M1 numerators added; A1 17/20
2. [3] M1 20% of 90 = 18 (or 90 x 0.8); M1 90 - 18; A1 72 pounds
3. Correct: A, C (exactly these options, no others)
4. [3] M1 change = 30; M1 30/400 x 100; A1 7.5%

## Grading
Mark each answer against its key. A pass is at least 50% of the marks.

## Outcome
Record the exam result through the scripts, never by hand.
